# 设计系统基线（Design System Baseline）—— 专业 B 端的「不山寨」铁律

> 本文件是 `ux-optimizer` 的**强制前置基线**。任何定制设计系统都必须**建立在组件库标准之上**，
> 而不是自造一套色板/圆角/阴影。绝大多数「看起来像山寨页面」的原型，根因都是**自造未成体系的颜色 + 手写样式覆盖组件库**。

---

## 一、核心原则：**继承标准，只做品牌映射**

| 层级 | 规则 |
|------|------|
| **组件库** | React → Ant Design 5；Vue → Arco Design。**默认继承其标准 token 与组件外观** |
| **主色** | 客户品牌色 → **映射到组件库标准色阶的最近档位**（antd：blue/geekblue/cyan/green/gold/orange/volcano/red/magenta/purple/lime 的 `-6`/`-7`）。**禁止**直接使用 Tailwind/自造 hex（如 `#2563eb`、`#1E3A8A`、`#E08A00`） |
| **语义色** | 固定用组件库标准：antd `colorSuccess #52c41a` / `colorWarning #faad14` / `colorError #ff4d4f` / `colorInfo #1677ff` |
| **中性色** | 固定用组件库标准：antd `#1f1f1f`（正文）/ `#595959`（次级）/ `#d9d9d9`（边框）/ `#f5f5f5`（布局底） |
| **尺度** | 圆角 / 字号 / 控件高度用组件库标准（antd 默认圆角 6、控件高 32）；企业控制台可整体降一档密度 |
| **覆盖方式** | **优先用组件库 token（`ConfigProvider.theme.token` / `components`）**；CSS 覆盖层仅用于 token 表达不了的密度/等宽数字/可访问性增强 |

> 一句话：**能靠 token 解决的，绝不手写 CSS；能靠标准色阶解决的，绝不自造 hex。**

## 三、企业控制台（Enterprise Console）基线

B 端专业感 = **结构 + 密度 + 硬边界**，而非「卡片 + 大留白 + 软阴影」。

| 维度 | 企业控制台基线 |
|------|----------------|
| 布局 | 深色侧栏（`#001529`）+ 浅色高密度内容区（`#f5f5f5`）+ 白色顶栏（48px，1px 底边，无阴影） |
| 圆角 | 收敛：4–6px（antd 默认 6） |
| 阴影 | 近乎取消，改由 **1px 边框**分界 |
| 表格 | antd Table `size="small"`，表头 `#fafafa`、`label` 12px 灰字、**等宽数字**、行高 ~36 |
| 标签 | antd Tag 标准尺寸，浅底深字，色/图标/文字三重表达 |
| 字号 | 正文 13、标题 14–20；不用超大字号 |
| 数字 | `font-variant-numeric: tabular-nums` |
| 动效 | 0.2s ease，克制 |
| 工具调用 / 流程日志 | 重做为**结构化活动面板**（1px 边框 + 左侧主色条 + 等宽 I/O + 右对齐状态），**不是软圆角聊天卡片** |

---

## 四、「山寨感」反模式清单（必须避免）

- ❌ 自造未成体系的 hex（Tailwind 色、随手挑的颜色）与组件库中性色混用。
- ❌ 满屏 8–12px 大圆角 + 明显投影的「卡片堆叠」。
- ❌ 用 999px 大胶囊承载状态标签。
- ❌ 手写 CSS 覆盖 antd 组件，却不使用其 token，导致视觉与生态不一致。
- ❌ 一套页面里出现多个相近但不统一的字号/圆角/间距。
- ❌ 工具调用/日志渲染成「聊天气泡卡片」而非结构化表格/活动流。
- ❌ 深色侧栏用自造深色（应用 antd 经典 `#001529`）。

---

## 五、在 SOP 中的落点

1. **Step 3 推导设计语言时**：先确定组件库（antd/arco）→ 把品牌色映射到标准色阶 → 语义/中性色取标准值 → 尺度取标准值。
2. **Step 6 产出 ux-audit.yaml 时**：`meta.mode` 若为「企业控制台」，按第三章基线；`designLanguage.colors` 必须全部是标准色阶值。
3. **Step 7 注入时**：**优先写 token**（`designAppTheme` 合并进 `ConfigProvider`）；CSS 覆盖层保持最小（密度/等宽数字/可访问性），不做大面积视觉重绘。
4. **Step 9 审计时**：逐项核对「反模式清单」，出现即回退到标准值。
