# 客户 AI 就绪度与战略洞察评估器 (AI Maturity Assessment)

此技能用于在拜访企业客户（尤其是与 CEO / CIO / CTO 等高层对话）前，进行系统化的业务与 AI 现状深度调研，输出一份具有麦肯锡咨询风格的 HTML 战略简报。

> [!IMPORTANT]
> **双重输出规范 (Dual Output Standard)**: 
> 当你使用此 Skill 时，必须**同时**输出两个部分：
> 1. **结构化 YAML**: 用于下一步的自动化处理和数据存档。
> 2. **交互式 HTML**: 用于最终用户的直观审查与演示。HTML 内部已集成“复制 YAML”功能，确保数据可溯源。
> 
> **输出路径与命名规范 (Output Path & Naming Convention)**:
> - **目录**: 输出到 `<公司/业务名>/` 公司/业务级目录；若产物属于**具体 AI 场景**（如某场景的测试数据集 / 故事地图 / Agent 本体等），**必须**放入 `<公司/业务名>/<场景名>/` 场景子目录（两层规范，详见 `agent.md` 第 2 节；场景级文件名需含场景名，如 `[公司]-[场景]-[业务类型].html`）。
> - **文件名**: HTML 文件名必须反映内容，格式为 `[公司/业务名]-[业务类型].html` (例如：`张雪机车海外销售-AI成熟度评估.html`)。
> 
> **视觉设计规范 (Visual Design Standard)**:
> - **样式风格**: 默认按照 `skills/design.md` 进行样式输出。
> - **底色模式**: 默认使用 **浅色底 (Light Mode)**。
> - **页面布局**: HTML 内容区撑满容器宽度（width: 100%），Header 采用统一精简样式（左侧标题+副标题、右侧操作按钮），内容超出屏幕时容器内可上下左右滚动。

## 适用场景

| 场景 | 说明 |
|------|------|
| **新客户拜访准备** | 首次接触目标企业老板前，快速建立对其业务和 AI 现状的全面认知 |
| **提案前调研** | 撰写 AI 转型提案前，系统梳理客户的 AI 就绪度和差距 |
| **竞争分析** | 评估目标企业在行业中的 AI 竞争力与差异化机会 |
| **内部战略对齐** | 在与客户对话前，内部对齐对该客户的认知与策略假设 |

## 核心架构

本技能采用 **LLM → YAML → Python → HTML** 的解耦架构：

1. **LLM**：负责从公开信息和非结构化描述中提取分析洞察，输出标准 YAML 数据。
2. **Compiler**：位于 `scripts/build_report.py`，负责解析 YAML 并结合 `templates/` 下的 Jinja2 模板生成麦肯锡风格 HTML。

## 分析框架（七大维度）

### 第一维：企业基本面 (Company Fundamentals)
- 企业基本信息：名称、总部、成立时间、规模、融资/上市情况
- 核心业务线拆解：各业务线的营收占比、增长态势、战略定位
- 组织架构：技术团队规模、AI/数据团队设置、汇报关系
- 商业模式：B2B / B2C / 平台 / SaaS 等

### 第二维：数字化转型成熟度 (Digital Transformation Maturity)
- 当前 IT 基础架构：云化程度、系统集成度、技术债务
- 数据基础设施：数据湖/仓、数据治理、数据质量
- 业务流程数字化：核心流程的自动化程度
- 数字化人才密度

### 第三维：AI 应用现状 (AI Current State)
- 已有 AI/ML 应用场景清单（生产环境 / 试点 / 规划中）
- AI 团队组成与规模
- AI 基础设施与技术栈（模型平台、MLOps 工具链）
- 近 2 年 AI 相关投资与采购
- 关键技术合作伙伴

### 第四维：AI 战略解读 (AI Strategy)
- 公开的 AI 愿景与战略表述
- AI 投资优先级领域
- AI 组织变革意图
- 对 AI 监管/合规的态度
- 高管（CEO/CTO）AI 相关公开言论解读

### 第五维：行业 AI 成熟度对标 (Industry AI Maturity Benchmarking)
- 所在行业的 AI 整体采纳率与成熟度
- 行业 AI 标杆企业案例
- 行业特有的 AI 机会地图
- 行业 AI 落地主要困难与风险
- 该企业在行业中的 AI 相对位置评估

### 第六维：差距与机会分析 (Gap & Opportunity Analysis)
- 企业 AI 现状 vs 行业基准的差距量化
- 快赢机会 (Quick Wins)：3-6 个月内可落地的 AI 场景
- 战略机会 (Strategic Bets)：中长期差异化机会
- 风险提示：数据合规、组织阻力、技术负债等

### 第七维：对话策略建议 (Conversation Strategy)
- 与客户老板对话时的核心议题建议
- 关键提问清单（按优先级排序）
- 痛点探测方向
- 价值主张切入点
- 潜在异议预判与回应策略

## 工作流 SOP

### Step 1 · 输入确认
确认以下信息（缺失项标注"待调研"）：
- 目标企业名称
- 所在行业
- 拜访对象（CEO / CIO / CTO / 其他）
- 已知背景信息（如有）
- 本次拜访的商业目标

### Step 2 · LLM 分析生成 YAML
- 读取 `references/prompt_zh.md`（角色设定 + 七大维度字段规范 + 麦肯锡风格约束）
- 根据七大分析维度，进行深度推理分析
- 将分析结果保存为结构化 YAML
- 将 YAML 保存至 `examples/<公司名>.yaml`

### Step 3 · 编译麦肯锡风格 HTML
```bash
python3 scripts/build_report.py examples/<公司名>.yaml examples/<公司名>.html
```

### Step 4 · 交付浏览
通知用户在浏览器中打开 HTML 文件，即可查看完整的 AI 就绪度战略简报，包含：
- 执行摘要
- 企业基本面仪表盘
- 数字化转型成熟度评分卡
- AI 应用现状矩阵
- AI 战略雷达图
- 行业对标五大维度热力图
- 差距分析 + 快赢机会清单
- 对话策略建议卡

## 可视化设计规范（麦肯锡风格）

### 整体调性
- **配色**：以深海军蓝 (`#003A70`) 为主色，辅助以麦肯锡蓝 (`#0077C8`)、石墨灰 (`#5A6570`)、象牙白 (`#F5F7FA`)
- **字体**：无衬线字体（系统默认），标题使用粗体 + 字距 2px
- **布局**：全宽卡片式布局，模块分区使用细线分割，留白充足
- **图表**：CSS 纯手工绘制（无外部图表库依赖），包含雷达图、进度条、热力矩阵

### 页面区域（自上而下）

| 区域 | 内容 | 视觉特征 |
|------|------|----------|
| **封面区** | 报告标题、企业名称、评估日期、保密声明 | 全宽深海军蓝背景 + 白色大字，副标题使用浅灰 |
| **执行摘要** | 6-8 句核心发现，分"现状判断"和"建议方向" | 左侧蓝色竖线引用风格，要点使用 • 符号 |
| **企业基本面仪表盘** | 基本信息卡 + 业务线拆解 + 组织架构简图 | 3 列卡片网格，每张卡片带图标和关键数字 |
| **数字化成熟度评分** | 5 维度 1-5 分评分卡 + 总分 | CSS 进度条（渐变色），每维度有简要说明 |
| **AI 应用现状矩阵** | 场景 × 成熟度矩阵（生产/试点/规划） | 表格形式，带颜色编码的状态标签 |
| **AI 战略雷达图** | 6 维雷达图（愿景/投资/人才/数据/技术/治理） | 纯 CSS 雷达图（conic-gradient + clip-path） |
| **行业 AI 对标** | 5 维度行业 vs 企业对比热力图 | 响应式网格，颜色深浅表示差距大小 |
| **差距与机会分析** | 差距量化 + 快赢机会 Top 3 + 战略机会 Top 3 | 卡片列表，带优先级标签和时间估算 |
| **对话策略卡** | 核心议题 + 关键提问 + 价值主张 + 异议预判 | 折叠面板（accordion），逐条展开 |

### 评分体系

| 分数 | 等级 | 含义 |
|------|------|------|
| 5 | 领先者 | 行业标杆，AI 深度嵌入核心业务 |
| 4 | 先进者 | 系统性布局 AI，有多场景落地 |
| 3 | 跟进者 | 有明确的 AI 战略和试点项目 |
| 2 | 起步者 | 初步探索 AI，缺乏系统规划 |
| 1 | 观望者 | 尚无实质 AI 投入 |

## build_report.py 核心能力

| 能力 | 实现方式 |
|------|----------|
| 防呆 YAML 解析 | 正则剥除代码块标记，`yaml.safe_load` |
| 评分卡渲染 | CSS 进度条 + 颜色编码 |
| 雷达图生成 | 纯 CSS（conic-gradient + clip-path） |
| 行业对标热力图 | CSS Grid + opacity 映射 |
| 折叠面板 | 纯 JS 手风琴交互 |
| 打印优化 | @media print 隐藏交互元素，优化排版 |
| 模板引擎分离 | Jinja2 + `templates/report_layout.html` |
