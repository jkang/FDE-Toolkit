为 Customer Support AI Agent 建立从“原型通过”到“正式发布”的客观量化准则。

Decision Gateway Criteria

“当 准确率 ≥90%，FCR ≥70%，响应延迟 ≤1.5s，用户点赞率 ≥60% 时，允许灰度上线。”

通过门禁：允许发布
未通过：执行回归优化

测试数据集策略

Golden Path 50%

验证核心功能链路与基准准确率。

Hard Cases 30%

检验模型处理复杂边界逻辑的鲁棒性。

Edge Cases 20%

测试系统异常处理与内容安全边界。

Evidence Tags

测试集必须包含中间产物标签（如检索 ID、提取字段），以便在指标未达标时进行归因分析。

四维一线法

MVP 验证不应仅看准确率，必须同步评估业务采纳、系统延迟与成本。只有四维达标，才具备发布资格。

  • 指标先于实现
  • 三明治测试集覆盖
  • 自动化闭环评估
