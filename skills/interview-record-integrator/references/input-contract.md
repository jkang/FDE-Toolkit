# 输入契约：三件套识别与缺失降级

> 本 Skill 的输入是**同一场访谈**的三份材料。识别、配对、缺失降级均按本文件执行。

---

## 一、三件套清单

| 材料 | 常见命名 | 提供什么 | 必需性 |
|---|---|---|---|
| **调研提纲** | `*-现状访谈提纲.md`（分册 / 通用册） | 章节骨架、问题号、★ 必问、▸ 量化项、价值流分段对照（如有）、原话摘录项 | 建议有；无则降级 |
| **人工记录** | `*-人工记录.md` / `*-现状访谈(人工记录).md` | 现场骨架 + 关键词（常直接写在提纲模板上） | 至少其一 |
| **AI 录音记录** | `*-录音记录.md` / `*-访谈录音记录.md` | 逐句转写：细节、数字、原话、多人对话 | 至少其一 |

> **最低要求**：人工记录与录音记录**至少有一份**；两份都有则按「人工记录打底 + 录音补全」合并。

---

## 二、场次配对规则

- 以**场次标识**配对（如「华东区-零售」「华南区-渠道」「总部-市场」）。
- 提纲可能来自**分册**（如 `零售-现状访谈提纲.md`）或**通用册**
  （一份覆盖多条业务线，人工记录常写在通用册模板上）——两者都可用作骨架。
- 配对存疑（命名不一致 / 多份候选）时**先问用户确认**，不擅自拼场次。

---

## 三、缺失降级规则

| 缺失情况 | 处理方式 |
|---|---|
| **无提纲** | 改用**链路归位**结构（按该场次实际业务链路设一级标题），并在文首说明所用链路。 |
| **无人工记录** | 仅用录音整理；文首「记录来源」只列录音，并注明「无现场人工记录」。 |
| **无录音记录** | 仅用人工记录整理；文首注明「无录音转写，内容以现场人工记录为准」；**不补细节、不臆造**。 |
| **三件套均缺提纲与人工记录** | 只有录音时按链路归位；若连录音也无 → **停止**，向用户索要材料。 |
---

## 四、读取顺序与要点

1. **先读提纲**：抄下章节标题与题号，建立输出骨架；记录 ★ / ▸ / ⤷ 标记项。
2. **再读人工记录**：判断它是「写在提纲模板上的批注」还是「独立笔记」；
   按题号把关键词填入骨架，标出每题「有 / 无」。
3. **最后读录音**：先读开头（日期 / 时长 / 关键词 / 参与人）与结尾（常含身份自述、场次说明），
   再通读正文回填；**同步执行 `caveats.md` 的 C 级转写错误处理**。

> 录音开头通常含：日期时间、时长、关键词列表、参会人姓名；结尾常有身份/称呼自述与收尾对话
> ——这两处是确定**受访人身份、访谈时间、时长**的关键位置。

---

## 五、输入侧防呆

- **禁止**把不同场次的材料混在一起整理。
- **禁止**用其他场次或公开资料填补本场次的空缺（那会污染事实底稿）。
- **禁止**把访谈提纲里的**提示词 / 话术 / 示例**当成受访人所述事实——提纲是提问工具，不是事实来源。
