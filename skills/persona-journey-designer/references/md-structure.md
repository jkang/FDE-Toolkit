## 字段说明

| 字段 | 要求 |
|---|---|
| 画像类型 | `主用户` / `次要用户` |
| 核心 Job | 一句动词驱动的短语（不是功能名） |
| 关键指标 | 该角色关注的 1–3 个指标 |
| 使用频次 | 每日 / 每周 / 每周期 / 临时 |
| Job Story | 固定句式：当…我想要…以便… |
| 起点 / 终点 | 目标触发 / 目标完成，各一句 |
| 旅程表 | 5–7 行；列固定为 `# 阶段 用户动作 触点 期望结果` |
| 产品介入点 | 一句，标明产品在旅程的哪几步帮忙（连接原型） |
| 矩阵图例 | ● 一期 · ○ 后续 · — 不适用 |
| 覆盖校验「是否显性」 | `显性` / `易忽略` |

---

## 硬性约束

1. 画像数量 2–5 类；必须区分主用户 / 次要用户。
2. 每类画像 2–4 个场景；每场景 5–7 步旅程。
3. 每条旅程必须写清**起点（目标触发）**与**终点（目标完成）**。
4. 每场景必须有「**产品介入点**」一句（标明产品在哪几步帮忙）。
5. 旅程表**不得**出现 UI / 字段 / AI 交互细节列。
6. 必须有「画像 × 场景矩阵」与「角色覆盖校验」两段。
7. 一线执行角色必须出现在画像清单中。
