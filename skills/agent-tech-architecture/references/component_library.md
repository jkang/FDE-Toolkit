# 组件类型 · 配色 · 形状对照表（Component Library）

本文件是编排图的「视觉语言唯一真源」。`scripts/build_tech_architecture.py` 与
`templates/tech_arch_layout.html` 均按此表把 YAML 的 `type` 映射为颜色 / 形状 / 图例。

|---|---|---|---|---|---|

## 二、边（edges[].style）

| style | 语义 | 画法 |
|---|---|---|
| `solid` | 正常流转 | 实线箭头，可带条件标签（通过 / 确认 / 高） |
| `dashed` | 回退 / Loop / 重试 / 升级 | 虚线箭头，标签建议含回退目标与次数（`不通过 ×2`、`超时重试 ×1`） |

## 三、模型分类（写进 nodes[].note 的小字备注）

| 备注写法 | 含义 |
|---|---|
| `(小模型)` | 意图 / 实体 / OCR / 专用预测等感知类模型 |
| `(专用模型)` | 单一任务的预测模型（如 ETA 预测） |
| `(LLM)` | 大模型：推理 / 解释 / 生成 |
| `(LLM · 读本体 R)` | 大模型 + 读取本体 |
| `(MCP · OMS · 写本体 W)` | 外部系统调用 + 写回本体 |
| `(RAG · HS 库)` | 检索增强，注明知识库名 |
| `(确定性)` / `(规则引擎)` | 无模型，走确定性服务 / 规则引擎 |
| `(Loop ×2)` | 回边与次数上限 |

## 四、资产归属门禁（Skill / MCP / KB / 本体 / Agent）

| 资产 | 承担 | 判据 |
|---|---|---|
| 本体 | 对象查询 / 关系遍历 / 规则校验 / 确定性动作 | 需要「事实与规则」的确定性读写 |
| Skill | 稳定专项任务，I/O 清晰、可独立验收 | 一段固定的输入→输出能力 |
| MCP | 访问外部数据 / 执行外部系统动作 | 需要跨系统读写 |
| KB / RAG | 法规 / SOP / 历史案例等非结构化知识 | 需要语义检索而非确定性查询 |
| Agent | 全局规划 / 调度 / HITL / 异常与降级 | 唯一规划者，不直接算数 |

## 五、Skill vs Sub-Agent 判定（写在 skills[].whyNotSubagent）

默认 `type: skill`。命中以下**任一**才置 `type: subagent`：
1. 需要自己的多步规划 / 工具选择循环（非预定义分支）；
2. 需要独立上下文 / 记忆；
3. 需要显著不同的模型 / 护栏 / 权限（涉钱、涉合规、需沙箱隔离）；
4. 需要独立部署 / 独立评测 / 独立迭代；
5. 长时运行或异步。

> 图上：`skill` = 圆角能力卡；`subagent` = 能力卡 + 顶部「自身循环 Plan→Act→Observe」徽标 + 「独立上下文」角标。
