# 质量审查框架

## 跨阶段一致性检查清单

### 阶段 1 → 阶段 2 一致性

- [ ] SWOT 中的"优势"有阶段 1 财务或业务数据支撑
- [ ] SWOT 中的"劣势"对应阶段 1 中发现的具体短板
- [ ] SWOT 中的"机会"与阶段 1 中的市场和战略动态信息一致
- [ ] SWOT 中的"威胁"基于阶段 1 中的竞争格局信息

### 阶段 2 → 阶段 3 一致性

- [ ] 北极星指标与阶段 1 中的核心业务模式匹配
- [ ] 每条业务策略至少关联一条 SWOT 交叉策略
- [ ] KPI 目标值相对于阶段 1 基线数据合理
- [ ] 策略的优先级排序与 SWOT 中的影响程度评估一致

### 全局一致性

- [ ] 三份报告中不存在相互矛盾的判断
- [ ] 信息来源的引用在各报告间一致
- [ ] 推断标注"[推断]"在所有报告中统一使用

## 五维质量评分

对最终输出按以下维度打分，每项 1-5 分：

### 1. 信息密度（1-5 分）

| 分数 | 标准 |
|------|------|
| 1 | 几乎无具体数据，全是概括性描述 |
| 2 | 有少量数据，但关键指标缺失 |
| 3 | 主要指标有数据，部分维度内容单薄 |
| 4 | 各维度数据充实，有对比和趋势 |
| 5 | 数据丰富、多维度交叉，信息密度高 |

### 2. 证据支撑（1-5 分）

| 分数 | 标准 |
|------|------|
| 1 | 无来源标注，无法验证 |
| 2 | 少数来源标注，多数论点无支撑 |
| 3 | 主要论点有来源，部分缺失 |
| 4 | 绝大多数论点有来源，推断已标注 |
| 5 | 所有论点有来源，推断全部标注，来源可信 |

### 3. 逻辑连贯（1-5 分）

| 分数 | 标准 |
|------|------|
| 1 | 三阶段之间断裂，无逻辑联系 |
| 2 | 有联系但跳跃大，中间缺少推导 |
| 3 | 逻辑基本通顺，个别环节薄弱 |
| 4 | 逻辑清晰，阶段间衔接自然 |
| 5 | 逻辑严密，每个结论都有清晰的推导链条 |

### 4. 可操作性（1-5 分）

| 分数 | 标准 |
|------|------|
| 1 | 纯分析，无可执行建议 |
| 2 | 有方向但过于笼统，无法直接行动 |
| 3 | 有具体建议，但缺少资源和时间线 |
| 4 | 建议具体，有优先级、资源和里程碑 |
| 5 | 可直接转化为 AI 规划的输入，行动清单明确 |

### 5. 业务相关性（1-5 分）

| 分数 | 标准 |
|------|------|
| 1 | 与指定业务类型几乎无关 |
| 2 | 泛泛公司分析，未聚焦业务类型 |
| 3 | 多数内容相关，部分偏离 |
| 4 | 紧扣业务类型，分析有针对性 |
| 5 | 深入业务细节，洞察精准 |

**合格线**：总分 ≥ 18 分（满分 25），且单项不低于 3 分。

## Agent 自我审查 (Self-Critique) 机制

作为执行此任务的 Agent，在向用户正式输出最终汇总报告之前，你必须强制进行一次内部的“自我审查 (Self-Critique)”：

1. **切换身份**：在思维链（或思考过程）中，将自己转变为严苛的企业战略分析师和质量审查专家。
2. **自我拷问**：使用以下 Prompt 结构对你的草稿进行逐项打分。
3. **自我纠偏**：如果发现任何维度的评分低于 3 分，或者存在前后矛盾，**立刻重写该部分**，然后再将最终完美版输出给用户。
