# AI 场景优先级矩阵 · 视觉设计规范（Visual Standard）

本 skill 目录不含示例报告图（无 `references/examples` 图片），**此文件即视觉标准的唯一依据**；
LLM 产出 HTML 时按下述规范渲染（与 `templates/matrix_layout.html` 固化样式一致）：

## 底色模式
- **浅色底（Light Mode）**：页面背景 `#F5F5F6`（`--zx-bg-secondary`），卡片/表头白底 `#FFFFFF`。

## 布局
- **内容区撑满容器宽度**：`.container` 默认 `max-width:1300px; margin:0 auto`；
  打印/全宽场景下内容区 `width:100%; max-width:none`，内容超出时容器内可横向滚动。
- Header 采用统一精简样式：左侧「品牌色块 + 标题 + 副标题」，右侧操作按钮
  （报告用主色蓝 `#1A6BC4`，次级按钮灰底 `#EBEEF2`），标题下沿 2px 分隔线。

## 配色
- 主色：品牌蓝 `#1A6BC4`；强调/告警：红 `#E63946`；成功 `#16A34A`、警告 `#F59E0B`、危险 `#DC2626`。
- 矩阵象限色：Quick Wins 绿 / Big Bets 橙 / Fill-ins 灰 / Avoid 红（语义区分象限）。
- 收益列浅红底 `#FFF1F2`、成本列浅蓝底 `#EBF4FD`、优先级列浅黄底 `#FEFCE8`。

## 页面结构（自上而下）
1. 页眉：标题 + 副标题 + 汇总统计（场景数 / P0/P1 计数等）。
2. 可折叠的**打分标准面板**（5×5 评估准则，含每维度 1-5 分细则）。
3. **维度详情评分表**：每场景一行，展示 7 维得分与综合优先级分。
4. **5×5 优先级矩阵**：收益均值(Y) × 成本均值(X)，彩色象限定位。
5. 内嵌「复制 YAML」按钮，确保数据可溯源；支持打印导出。

## 字体与圆角
- 字体：`Inter` + `Noto Sans SC`；圆角 `2px/8px/12px` 三级；正文 `13-14px`，行高 `1.6`。
