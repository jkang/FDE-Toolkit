# 简洁铁律：删什么、控多少

> 提纲是**现场边问边记的工具**，不是研究报告。越短越能被真正用起来。
> 以下规则默认执行；确需突破时须有明确理由。

---

## 一、结构：固定 3 大段，不新增块

- 只允许 **3 大段**（角色与业务背景 / 信息流现状 / 理想态与资源重排）；
  时长紧张时压成 **2 大段**（理想态并入信息流现状）。
- **禁止**新增与骨架重复的小节（如「系统与数据现状」「颗粒度分层」这类可在既有问题里追问的内容）。
- **禁止**产出附录：现场记录模板、受访者版、场景探针附录、价值流分段对照表。

> 为什么：现场记录是**直接在提纲问题下写批注**的，另出「现场记录模板」从来不被使用；
> 场景探针写成附录就会与正文重复。

---

## 二、题量：能少则少

| 约束 | 上限 |
|---|---|
| 大段 | 3（或 2） |
| 每大段小节 | ≤ 4 |
| 每小节问题 | ≤ 4 |
| ★ 必问占比 | ≤ 40% |
| 单册总量 | ≤ 约 45 题 / 100 行 |

- **合并同义题**：同一个信息只问一次，不换词重问。
- **删「三合一」长题**：一道题问 3 件事 → 拆开或只留最关键的一件。
- **★ 只给真正的必问**：时间不够也要问的才打 ★；打多了等于没打。

---

## 三、行文：一题一行

- 一题一行，追问用 `⤷` 缩进一行，量化用 `▸` 缩进一行；**不写段落式长问**。
- **提示（▸ 提示）简短**：只列关键词，等受访者说完再补；不写成话术。
- **使用说明压到 4 行**：用途 / 对象 / 符号 / 原则（含现场记录方式）。
- **不写引导式提问**：避免「如果有个工具你会不会……」「是不是因为……」这类把答案塞给受访者的问法。

---

## 四、删除清单（默认不要）

- ❌ 现场记录模板 / 填写模板 / 受访者版
- ❌ 场景专属探针附录（改为内嵌）
- ❌ 价值流分段对照表（如需，压成文首一行，不占块）
- ❌ 重复的「使用说明 / 符号约定 / 访谈原则」（全册只出现一次）
- ❌ 与本次访谈目的无关的通用问题

---

## 五、交付前瘦身检查

- [ ] 只有 3（或 2）大段，没有新增块
- [ ] 没有任何附录
- [ ] 每小节 ≤ 4 题；★ ≤ 40%；总量 ≤ 约 45 题 / 100 行
- [ ] 没有换词重问的重复题
- [ ] 没有段落式长问 / 引导式提问
- [ ] 使用说明 ≤ 4 行
