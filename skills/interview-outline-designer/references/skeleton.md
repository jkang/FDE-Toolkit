# 3 大段骨架与问题模板

> **通用模板**：适用于任何客户、业务线与岗位。1.3 的「核心业务全周期」按场景实例化
> （销售=客户全生命周期 / 服务=工单全流程 / 项目=项目全周期 / 职能=事项处理全流程）；
> 1.4「拓展与来源」仅在角色有获客 / 接单 / 新增环节时保留。
> **占位词**（按场景替换）：`<业务线/场景>` `<受访角色>` `<典型对象>` `<对象层级>` `<终端/现场>` `<成效口径>`
> **符号**：★ 必问 ｜ ▸ 量化（追到数字）｜ ⤷ 追问
> 目标：单册 ≤ 约 45 题 / 100 行；每小节 ≤ 4 题；★ ≤ 40%。

---

## 文首（固定 4 行）

```markdown
# <客户> · <业务线/场景>现状访谈提纲

> **用途**：还原 <业务线/场景> 一线业务信息流的「捕捉 → 处理 → 决策 → 复用」现状，为后续现状分析与机会点提供事实依据。
> **对象**：<受访角色>（典型 <典型对象>）｜**时长**：约 <__> min
> **符号**：★ 必问｜▸ 量化（追到数字）｜⤷ 追问
> **原则**：只还原现状、不评价不引导；一切落到具体（「最近一次是什么时候」「举个例子」），区分「应该这样」与「实际这样」；追问证据（谁做 / 多久 / 来源）。现场直接在本提纲对应问题下记录（🟢 事实 / 🟡 感受 / 🔵 期望）。
```

## 一、角色与业务背景

### 1.1 角色与团队
1. ★ 您负责哪条线、哪些区域、多大规模团队？团队怎么分工？
   ▸ 量化：团队 __ 人；覆盖 <客户> __ 家；人均覆盖 __ 家
2. 您的核心职责和考核指标是什么？分几个、各占多少？
   ▸ 量化：指标 __ 个；收入 __%、其他 __%
3. 一个典型工作日 / 周，时间怎么分配？
   ▸ 量化：跑 <终端> __ 天/周；开会 __ 次/周；看数据 __ 次/周

### 1.2 目标与考核口径
4. ★ 目标怎么定？自上而下还是自下而上？主要依据什么？
   ▸ 量化：考核周期（月 / 季 / 年）；一次定目标开 __ 次会
5. 除了收入，还有哪些目标 / KPI？请尽量列全。
   ▸ 提示（等说完再补）：<按业务线补充 4–6 个典型指标>
   ▸ 量化：哪些进考核、哪些只监控 __
6. 谁跟踪这些目标？多久看一次？怎么发现偏离？偏差怎么调整？数据拿不到时怎么处理？

### 1.3 核心业务全周期（挑一个典型对象，从头讲）
> 话术：「不要抽象流程，就挑一个您最熟的 <典型对象>，从头讲一遍。」
7. ★ 挑一个您最熟悉的典型 <典型对象>，讲它怎么进入视野？谁找的谁？
8. 决定合作 / 投入 / 受理前，您看什么、问什么、查什么？跟谁谈、谈几轮、谈什么？
9. 首次合作 / 交付 / 上量怎么定？依据？
10. ★ 多久去一次？见谁？待多久？去之前准备什么、去之后做什么？
    ▸ 量化：__ 次/月；每次 __ 小时；见 __ 人
11. ★ 怎么知道 <成效口径>（卖得动 / 用得动 / 有进展）？看什么、问谁、多久看一次？不行怎么办？
    ▸ 量化：__ 次/月；数据滞后 __ 天
12. 复盘怎么复盘？结论怎么变下一步动作？什么情况下减少 / 停止投入？续约 / 续做哪些条件会变？

### 1.4 拓展与来源（获客 / 接单 / 新增；无此环节可删）
13. 现在以存量挖掘为主，还是不停挖新对象？两者大概什么比例？为什么？
    ▸ 量化：存量 __% / 新增 __%
14. ★ 线索 / 来源从哪里来？哪类质量最好？怎么收集 / 管理、记在哪（系统 / Excel / 群）？
    ▸ 量化：各来源占比 __%；每月线索量 __ 条
15. 从线索到成交走什么流程？最难是哪一步？开发与维护投入怎么分配？

## 二、信息流现状（捕捉 → 处理 → 决策 → 复用）

### 2.1 信息捕捉与研究
16. ★ 每次拜访主要捕捉哪些信息？逐条列（列到列不出）。
    ▸ 提示（等说完再补）：<按业务线补充 4–6 个典型维度>
17. 哪些必记、哪些顺带看、哪些看完就过去？记录率大概多少？
    ▸ 量化：必记 __ 条；实际记下 __ 条
18. 一次拜访能记多少？多久之内记？记在哪（手机 / 本子 / 系统 / 群）？
    ▸ 量化：__ 分钟内记
19. 围绕这个客户，平时做哪些研究？收集什么、从哪来、多久一次、谁做、花多久？
    ⤷ 上一次是什么时候？能翻出来看看吗？（**要看实物**）

### 2.2 信息分析与判断
20. ★ 您怎么判断生意健不健康？什么算良性、什么算不健康？分哪几级判断？
    ▸ 量化：各级看 __ 个指标；判断频次 __
21. 判断时看哪些数据 / 信息？从哪来？多久判断一次？谁做？什么颗粒度？
22. 会不会担心「中间环节积压、没到最终使用方」？怎么发现？
    ▸ 量化：周转 __ 天；积压金额 __ 万元
23. 有没有「积压 / 失效变成负担」的具体例子？怎么发现的？晚了还是早了？
24. 判断准确率大概多少？最可靠 / 最不可靠的信号是什么？
25. ★ 怎么判断一个客户 / 区域下一步增长在哪？看哪些维度、用什么工具、多久做一次？哪些判断数据给不出、只能靠经验？

### 2.3 信息处理、决策与记录
26. ★ 收集到的信息最后去哪了？谁在用？从「信息」到「决策」，中间谁加工、怎么加工？
27. 您会不会有一些模模糊糊的判断和思考？会记录吗？记在哪？之后会再看吗？
    ▸ 量化：一周大概 __ 个；记录下来的 __ 个
28. 好销售的「临场直觉」具体是什么？举个例子。能不能教给新人？现在怎么传？
29. ★ 团队的信息 / 经验靠什么传？（口头 / 周会 / 案例 / 话术 / 群）
30. ★ 现在最大的信息断点在哪？（哪里最「进不来 / 出不去」）

## 三、理想态与资源重排

### 3.1 理想方式
31. 如果设计一个比较可行的最理想方式，您希望一线的信息捕捉和决策是什么样？最想先改善哪个环节？
32. 对「用设备 / 工具帮忙捕捉（甚至不用刻意记）」怎么看？团队能接受吗？顾虑？
33. 如果只能改一件事，您选什么？还有什么我们没问到、但很重要的？

### 3.2 资源重排（投射题）
34. ★ 如果现在为您安排**两个大学毕业生做助理**：他们不熟悉业务，但通用技能很强（整理文档、做 PPT、处理数据、数据分析），学习能力强、能接受反馈；除了不擅长应酬，其他都能做。**如果目标是三个月内让目标 KPI 有显著提升，您会如何安排他们的工作？**
    ⤷ 先让他们接手哪 2–3 件事？哪些绝对不放心交？三个月怎么分工？产出给谁用？

> 访谈人注意：本题为投射题，用来看受访者心里真正的瓶颈与最想被替代的环节；答案不计入对方案的直接需求。

### 3.3 管理者视角
35. ★ 作为管理者：当前管理一线最大的痛点和问题是什么？最期望 AI 可以帮忙做什么？
