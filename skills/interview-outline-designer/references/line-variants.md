# 场景适配：术语替换与探针内嵌

> 骨架是固定的 3 大段，**适用于任何业务线 / 岗位**。场景差异**只做两件事**：
> ① 术语替换（把占位词换成该场景的说法）；② 探针内嵌（把 2–4 个特有追问并入既有问题）。
> **禁止**为某个场景新增小节、新增附录。

---

## 一、占位词表

| 占位词 | 含义 | 换法示例 |
|---|---|---|
| `<业务线/场景>` | 被访谈的业务线或场景 | 渠道销售 / 客户服务 / 生产运营 / 财务职能 |
| `<受访角色>` | 受访人角色 | 区域负责人 / 客服主管 / 车间主任 / 财务经理 |
| `<典型对象>` | 讲全周期时的主线对象 | 一个客户 / 一张工单 / 一个订单 / 一个项目 |
| `<对象层级>` | 对象内部的层级 / 环节 | 总部 / 分部 / 门店；提单 / 处理 / 回访 |
| `<终端/现场>` | 最终发生 / 交付的场所 | 门店 / 客户现场 / 产线 / 柜台 |
| `<成效口径>` | 判断「有成效」的依据 | 销量 / 使用量 / 达成率 / 及时率 / 良率 |

## 二、术语替换示例（不同场景）

| 骨架原词 | 渠道销售 | 客户服务 | 生产运营 |
|---|---|---|---|
| 典型对象 | 客户 | 工单 | 生产订单 |
| 层级 / 环节 | 一级 / 二级 | 提单 / 处理 / 回访 | 计划 / 车间 / 班组 |
| 首次环节 | 首单 / 铺货 | 首次受理 / 响应 | 首次排产 / 投料 |
| 成效口径 | 销量 / 回款 | 解决率 / 处理时长 | 产量 / 良率 |
| 关键指标 | 覆盖率 / 复购 | 首次解决率 / 满意度 | 达成率 / 停机时长 |

> 替换只改**名词**，不改**问题意图**；替换后仍应能直接照着问。
> 替换后若某小节整体不适用（如职能岗位无「线索拓展」），**直接删该小节**，不硬凑。

## 三、探针内嵌示例（并入既有问题，不新增块）

**渠道销售**
- 并入 1.3-11（成效）：一级 / 二级分别怎么判断经营健康度？**流向 / 出货数据能回答什么、不能回答什么**？真实库存看得到吗、看不到怎么估？
- 并入 1.4-14（来源）：内部数据（流向 / 未覆盖名单）能贡献多少线索？

**客户服务**
- 并入 1.3-10（日常）：工单从提单到关闭经过哪几个环节、分别谁处理？
- 并入 2.2-20（健康度）：怎么判断服务量是否健康（积压 / 超时 / 重复提单）？
- 并入 2.3-27（记录）：客户反馈 / 疑难工单有没有沉淀、有没有回流到流程？

**生产运营**
- 并入 1.3-10（日常）：班前会 / 巡检 / 交接班分别看什么、记在哪？
- 并入 2.1-16（捕捉）：设备异常 / 质量波动 / 物料短缺，分别谁先发现、怎么上报？
- 并入 2.2-22（积压）：在制品 / 半成品积压怎么发现、多久发现？

**职能岗位（财务 / HR 等）**
- 并入 1.3-10（日常）：一个事项从发起、审批到办结经过哪些节点？
- 并入 2.2-20（健康度）：怎么判断办理是否顺畅（积压 / 退回 / 重复沟通）？

## 四、新场景推导法（无现成示例时）

按顺序回答 6 个问题，即可完成适配：

1. **对象是谁**：骨架里的「典型对象」在这个场景指什么？
2. **层级 / 环节**：从起点到终点经过哪几层 / 哪几个环节？各叫什么？
3. **现场在哪**：最终「发生 / 交付 / 见效」在哪个场所或系统？
4. **凭证是什么**：一次交易 / 交付 / 办结的凭证是什么（合同 / 订单 / 工单 / 记录）？
5. **成效口径**：判断「有成效」看哪个数（销量 / 使用量 / 达成率 / 及时率 / 良率）？
6. **特有信息**：这个场景独有的 2–4 条关键信息是什么？→ 内嵌到最相关的既有问题。

> 输出后自查：**有没有因为该场景而新增段落？** 有 → 退回，改为内嵌或删去。
