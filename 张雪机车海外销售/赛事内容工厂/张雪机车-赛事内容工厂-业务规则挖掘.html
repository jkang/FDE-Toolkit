高光片段判定与打分规则 使用点 · 高光片段识别与打分
①决策因子
精彩度（Action Intensity）：超车/贴身缠斗/事故/极限压弯等动作激烈程度 (来源 多模态视频理解模型)
叙事价值（Narrative Value）：是否改变比赛结果（夺冠/反超/退赛）或形成情绪张力 (来源 赛事数据库 + 视频理解)
品牌相关度（Brand Relevance）：是否含 ZXMOTO 车手/涂装/赞助露出 (来源 品牌VI/赞助标记)
历史互动偏好：历史高互动素材中同类镜头的表现 (来源 历史高互动内容素材库)
→
②逻辑分支
品牌相关度高 + 叙事价值高（夺冠/反超） → → 置顶为封面级高光并优先成片
精彩度高但品牌露出弱 → → 入选高光但叠加品牌角标补足露出
高光分低于阈值或候选不足 → → 回退候选池或拉人判定
→
③分支动作
综合精彩度/叙事价值/品牌相关度/历史偏好对镜头打分，产出高光片段清单。
→
④冲突仲裁
品牌相关度 ＞ 叙事价值 ＞ 精彩度 ＞ 历史互动偏好；赛事结果类镜头优先于纯动作镜头。
例外/HITL：高光分低于阈值 / 候选不足 → 回退候选池或拉人判定
平台适配规则（时长/比例/编码/拆条） 使用点 · 平台格式适配
①决策因子
平台时长上限：YouTube/TikTok/Instagram/Reels 各自时长上限 (来源 各平台内容规范)
画幅比例：竖屏 9:16 / 横屏 16:9 / 方形 1:1 要求 (来源 各平台内容规范)
编码与码率：平台推荐编码、码率与文件大小上限 (来源 各平台内容规范)
→
②逻辑分支
成片时长 ≤ 平台上限且比例匹配 → → 直接适配输出
成片超时长上限 → → 自动裁切高光核心段或拆条为多集
比例不匹配 → → 智能重构画幅（主体追踪裁切/加安全边）
→
③分支动作
按各平台硬规范批量适配时长/比例/编码，超限自动裁切或拆条。
→
④冲突仲裁
合规（时长/编码硬约束）优先于画质；超限必须先裁切/拆条再适配，不得强推超限内容。
例外/HITL：编码转换失败 → 重试 2 次→降级标准编码并标注
最佳发布时间与排期规则 使用点 · 发布排期与最佳时间选择
①决策因子
目标市场时区：各目标市场本地活跃时段 (来源 平台开放数据/分析平台)
历史时段互动表现：各市场历史发布时段的互动/完播表现 (来源 互动与转化效果数据)
热点时效窗口：赛事热点衰减速度（比赛结束后的黄金传播窗口） (来源 赛事赛程)
→
②逻辑分支
处于热点黄金窗口 + 目标市场活跃时段 → → 立即排期发布
热点窗口与活跃时段不重合 → → 优先抢热点窗口发布，后续补发第二波
档期冲突/热点已过期 → → 顺延或提示人工调整选题
→
③分支动作
结合时区、历史互动与热点窗口生成发布排期，抢赛事传播黄金期。
→
④冲突仲裁
热点时效性 ＞ 本地活跃时段；赛事热点转瞬即逝时优先抢窗口，不为等活跃时段牺牲时效。
例外/HITL：档期冲突 / 热点过期 → 顺延或提示人工调整
品牌红线与合规分级规则 使用点 · 品牌调性与内容红线终审使用点 · 脚本抽检确认
①决策因子
品牌调性一致性：内容是否符合 ZXMOTO 品牌调性与视觉规范 (来源 品牌调性/内容红线)
内容红线命中：是否触碰政治/宗教/暴力/竞品贬损等红线 (来源 品牌红线 + 文化禁忌库)
事实准确性：车手/成绩/名次等事实是否与赛事数据一致 (来源 WSBK 赛事数据库)
→
②逻辑分支
调性一致 + 无红线命中 + 事实准确 → → 放行进入排期发布
调性偏差或表述问题（非红线） → → 退回修改后重新送审
触碰内容红线/事实重大错误 → → 拦截，禁止发布并升级品牌内容经理
→
③分支动作
对外内容发布前的品牌调性、红线与事实三级校验，红线一票否决。
→
④冲突仲裁
红线命中或事实重大错误者一票否决（不得放行）；调性偏差可修改后复检。
例外/HITL：触碰品牌红线/文化禁忌 → 退回修改或拦截（对外必停确认）
效果归因与内容策略优化规则 使用点 · 效果归因与内容策略优化
①决策因子
互动率差异：本批内容互动率相对基准的偏离 (来源 互动与转化效果数据)
高光类型偏好：哪类高光/叙事/平台组合表现更好 (来源 互动数据 + 历史高互动素材库)
样本量充分性：数据量是否足以支撑策略调整 (来源 分析数仓)
→
②逻辑分支
样本充分 + 某类高光显著更优 → → 上调该类高光权重并更新偏好库
样本充分但差异不显著 → → 保守微调，不改变主策略
样本不足或波动大 → → 不调整，继续观察
→
③分支动作
把互动效果归因到高光选择/脚本风格/平台/时段，回流更新内容策略与高光偏好。
→
④冲突仲裁
样本充分性为前置门槛；数据不足时宁可不动，避免被噪声带偏策略。
例外/HITL：样本不足/波动大 → 保守微调或不调整
