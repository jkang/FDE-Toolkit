6 条链共享读写本体 / 按需调用 MCP
共享底座
🧱 本体（确定性底座）

读 R：赛事事件/车手/成绩（叙事要素）、品牌调性与内容红线（约束）、平台内容规范（适配）、目标市场文化偏好与禁忌（本地化）。
写 W：高光片段清单、多语言脚本、内容成品/内容包、发布记录、效果指标/高光偏好权重。
对象 / 关系 / 状态迁移 + 业务事实；Skill 读写本体，不靠 LLM 猜名次、猜平台规范。

🔌 MCP / 外部系统

调用点：WSBK 赛事数据库（赛事/成绩/对战）、视频剪辑 API（Runway/Descript）、语音合成 API（ElevenLabs/Azure TTS）、社媒管理平台（Hootsuite/Sprinklr）、数据分析平台（Google Analytics/平台开放数据）。
仅需要外部读写的步骤才走 MCP；未接的标 N/A。

📚 知识库 / RAG

检索点：多语言解说脚本模板库、目标市场文化偏好与禁忌库、品牌 VI 规范与视觉标准手册、平台标签与 SEO 关键词库、历史高互动内容素材库。
规则校验走规则引擎而非向量检索；模板/禁忌/VI/SEO 等非结构化知识走 RAG。

🩷 异常池（人工终审）：高光候选不足 / 文化禁忌无法改写 / 剪辑或 TTS 合成失败 / 平台编码失败 / 发布失败或账号异常 / 数据延迟缺失 / Loop 超限 → 升级人工，附上下文摘要。

失败 / 降级 / 兜底

触发处理类型
素材损坏 / 授权未 cleared提示重新上传或补充授权，不阻塞后续分站流程fallback
高光分低于阈值 / 候选不足回退候选池 → 拉内容团队人工判定escalate
赛事数据缺失导致叙事价值无法判断降级为仅视频理解并标注待核对fallback
命中文化禁忌且无法在不改变事实前提下改写自动改写/降级 → 仍冲突拉品牌内容经理裁决escalate
剪辑 API 失败 / 某语种 TTS 合成失败重试 2 次 → 切换备用 TTS / 降级标准模板retry / fallback
平台编码转换失败 / 超时长上限重试 2 次 → 降级标准编码；超限自动裁切或拆条retry / fallback
触碰品牌红线 / 事实重大错误一票否决拦截，禁止发布并升级品牌内容经理escalate
发布失败 / 账号异常 / 档期冲突重试 2 次 → 转人工发布；热点过期顺延或提示调整retry / escalate
效果样本不足 / 波动大不调整策略，继续观察并标注fallback

KPI 锚定（链路 → 指标）

赛事内容产出时效① 素材理解高光 + ③ 剪辑配音 + ④ 平台适配　3 天 → 30 分钟
多语言内容单位成本② 多语言脚本 + ③ 配音　外包本地化 → AI 自产，↓90%
内容互动率① 高光打分 + ② 脚本 + ⑥ 效果回流　↑35%
社媒内容日更量④ 平台适配 + ⑤ 发布编排　日更 3-5 条多平台
内容合规通过率⑤ 品牌红线终审　红线一票否决 + 对外必停

护栏落点

事实性计算（高光分 / 平台适配 / 排期 / 归因）走确定性规则引擎 / 本体，LLM 不产出事实与数值
对外发布（多平台自动发布）必须品牌调性与内容红线人工终审放行，禁止静默发布
品牌红线 / 文化禁忌红线命中一票否决；跨市场版本不得直接复用
素材授权授权未 cleared 不得对外发布
平台硬约束超时长/编码硬约束不得强推，须先裁切/拆条再适配
HITL 闸门品牌终审、多平台发布、策略复盘在架构层有落点，不写在提示词里
⚠️ 口径待确认（MCP vs 本体）：本方案把「WSBK 赛事数据库 / 剪辑 API / TTS / 社媒平台 / 数据分析平台」画成 MCP 外部调用；若确认「业务数据全部来自绑定本体」，则相应归入本体/内部服务并在底座标 N/A。二者需二选一后再定稿。
⚠️ 阈值待确认：高光分阈值、文化禁忌改写判定口径、各平台时长上限版本需业务专家坐实；未确认前原型按决策模型类规则默认值演示。
