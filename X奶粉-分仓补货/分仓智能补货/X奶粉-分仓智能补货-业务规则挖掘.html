缺口分级规则（DOS 分级） 使用点 · 计算各仓库存天数并判定缺口等级使用点 · 计算各仓目标备货率与补货优先级
①决策因子
库存天数 DOS：DOS=(库存+在途+分配)/日均销售计划 (来源 现货库存/在途库存/销售计划)
未来14天需求：分仓×SKU 未来 14 天销售计划合计 (来源 销售计划表)
促销计划：该 SKU 是否处于促销放量期（140+ 广促品指标） (来源 促销管理系统)
→
②逻辑分支
DOS < 7 天（且可发量+在途 < 未来7天需求） → → 判定红色·紧急补货，优先进入分配
7 ≤ DOS < 14 天 → → 判定黄色·常规补货
DOS > 60 天 且 无促销 → → 判定蓝色·积压预警，建议控量
DOS 落在 7/14/60 天边界 → → 标记边界冲突，转人工确认
→
③分支动作
按 DOS 与促销口径把全仓网分为红（紧急补货）/黄（常规补货）/蓝（积压预警）三级，驱动分配优先级。
→
④冲突仲裁
可发量约束 > 时效优先 > 补货优先级；促销期抑制蓝色积压预警（DOS 高但促销在途不判积压）。
例外/HITL：DOS 阈值边界冲突、计划/库存口径异常 → 拉人（物流计划岗确认）
备货率与目标备货率计算规则 使用点 · 计算生产备货率与订单完成率使用点 · 计算各仓目标备货率与补货优先级
①决策因子
生产备货率：(现货+在途+本月已出库)/销售计划 (来源 库存系统+实际销量+销售计划)
订单完成率：(当月未发+本月累出)/销售计划 (来源 未发订单+实际销量+销售计划)
旬度标准进度：分旬标准销售进度（中旬标准 50%） (来源 业务 SOP)
区域类型：核心/偏远区域，影响备货率上浮 (来源 仓主数据)
→
②逻辑分支
订单进度 ≤ 旬度标准进度 → → 目标备货率=订单进度+20%
订单进度 > 旬度标准进度 → → 目标备货率上浮并触发人工确认
目标备货率 > 100% → → 封顶 100%
偏远区域仓 → → 在目标备货率基础上上调缓冲
→
③分支动作
按「目标备货率=订单进度+20% 封顶100%」计算各仓目标备货率，并据此排序补货优先级。
→
④冲突仲裁
目标备货率封顶 100%；服务水平（不断货）优先于周转优化。
例外/HITL：订单进度超限或目标备货率>100% → HITL 人工确认
多约束分配量优化规则 使用点 · 计算建议补货量使用点 · 选择发货仓并拆分多仓补足使用点 · 生成多版分配方案使用点 · 人工确认与微调分配量
①决策因子
京慧建议量：京慧一盘货给出的初始建议补货量（参考基线） (来源 京慧一盘货)
可发量：发货仓库存-已分配量（典型位置：现货库存「可发量」列） (来源 现货库存表)
运输时效：基地仓→销售仓的运输时效/仓网距离 (来源 仓网主数据)
多约束集合：库存/在途/待检/合格/新鲜度/促销约束 (来源 库存/大日期/促销)
→
②逻辑分支
可发量覆盖缺口 且 存在时效最优仓 → → 就近优先选仓
时效最优仓可发量不足 → → 拆分多仓补足
急缺仓（红） → → 急缺优先，分配量向红色仓倾斜
积压仓（蓝） → → 积压控量，不再增配
促销放量仓 → → 分配量按促销上浮（偏离京慧建议量）
→
③分支动作
以京慧建议量为基线，在多约束下全局求解分配量与发货仓，生成均衡版/优先版多版方案，偏离京慧建议量必停确认。
→
④冲突仲裁
可发量约束 > 时效优先 > 京慧建议量；分配后须满足库存天数/安全水位约束；凑车微调允许 ±200 件。
例外/HITL：建议量偏离京慧建议量 → 写入前必停（HITL）；约束冲突无法求解 → 输出备选并拉人；修改超约束 → 退回重算
补货单校验规则 使用点 · 校验收发仓/SKU/数量/时效
①决策因子
收发仓合法性：发货仓为基地仓、收货仓为销售仓且在册 (来源 仓主数据)
SKU 在册：SKU 编码存在于产品主数据 (来源 产品主数据)
数量约束：补货数量 ≤ 发货仓可发量 (来源 现货库存)
时效约束：运输时效满足调入仓 ETA 要求 (来源 仓网主数据)
→
②逻辑分支
4 项全部通过 → → 允许进入下发（gate）
库存不足（数量>可发量） → → 退回调整并拉人
时效超期 → → 退回调整并拉人
收发仓/SKU 字段缺失或非法 → → 退回补正并拉人
→
③分支动作
对补货单做收发仓/SKU/数量/时效 4 项确定性校验，校验通过率与漏判率为验收门槛。
→
④冲突仲裁
库存不足/时效超期/字段缺失三项不得漏判；全部通过后才可进入人工下发门禁。
例外/HITL：校验不过 → 退回调整并拉人（物流计划岗）
入库差异判定规则 使用点 · 核对入库实收与差异
①决策因子
调拨数量：补货单/调拨单上的应发数量 (来源 补货单)
实收数量：WMS 入库验收的实际收货数量 (来源 WMS)
差异率：(调拨数量-实收数量)/调拨数量 (来源 计算字段)
破损率：破损数量/调拨数量 (来源 WMS/异常工单)
→
②逻辑分支
差异率 ≤ 0.5% → → 按实收同步并标记正常损耗
差异率 > 0.5% → → 生成差异处理单，推送财务与仓管追责
破损率 > 1% → → 生成独立异常工单
→
③分支动作
以 0.5% 差异率、1% 破损率为阈值判定正常损耗或生成差异单追责。
→
④冲突仲裁
差异未关闭前，差异数量不得计入可发量；正常损耗按实收直接同步。
例外/HITL：差异率>0.5% / 破损率>1% → 拉人（仓储/物流岗处理）
复盘调参规则 使用点 · 统计复盘指标并生成调参建议
①决策因子
时效达成率：按期到达批次/总批次 (来源 TMS 台账)
缺货缓解率：缺货缓解仓次/缺货总仓次 (来源 库存监控报表)
周转率：库存周转天数同比变化 (来源 库存监控报表)
入库差异率：差异数量/调拨数量 (来源 WMS)
→
②逻辑分支
时效达成率 < 90% → → 优化物流/上调安全水位
缺货缓解率 < 85% → → 优化需求预测/促销上浮
周转率同比降幅 > 10% → → 下调安全水位/加强促销联动
全部达标 → → 维持参数并记录基线
→
③分支动作
以时效≥90%、缺货缓解≥85%、周转同比降幅≤10%、差异率≤0.5% 为阈值，自动生成调参建议并审批生效。
→
④冲突仲裁
多项指标矛盾时：时效达成率（服务水平）优先于周转优化。
例外/HITL：指标异常恶化或调参冲突 → 拉人审批（物流计划岗），参数下一周期生效

分货方案模板
使用点 · 生成多版分配方案使用点 · 人工确认与微调分配量
固定骨架（章节 / 表头）
① 方案头
固定：固定栏（分货周期/仓网范围/方案版本 A/B/生成时间）
动态：随周期与版本动态填充
② 分配明细表
固定：固定列（收货仓/SKU/京慧建议量/可发量/分配量/分配后库存天数/优先级）
动态：随多约束求解结果动态填充
③ 效果预估
固定：固定栏（分配后 DOS/备货率/周转/新鲜度预估）
动态：随分配结果动态计算
④ 待确认项（HITL）
固定：固定栏（京慧建议量偏离项/约束冲突项/人工修改项）
动态：随偏离与修改动态生成
动态字段来源
分配量 ← 来自多约束分配优化规则（可发量/时效/促销约束求解）
分配后库存天数 ← 来自 DOS 计算口径
待确认项 ← 来自京慧建议量偏离/约束冲突/人工修改留痕
生成规则：标准分货周期自动生成均衡版/优先版多版方案；人工修改分配量后自动重新校验多约束。 合规：分配量不得超过可发量；目标备货率封顶 100%；人工修改必须填写修改原因并留痕；偏离京慧建议量必须经 HITL 确认。
典型 · 均衡版方案 · 多仓多 SKU 一次算完，红色急缺优先、蓝色积压控量，分配后库存天数达标 反面 · 分配量超可发量/缺 HITL 确认 · 禁止分配量超过可发量下发；禁止未确认京慧偏离项即写入

动态：随阈值触发动态生成
