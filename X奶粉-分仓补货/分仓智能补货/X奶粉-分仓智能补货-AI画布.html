AI 人机流程
改造后的完整人机协同流程（人 / Agent / 人机协同）
  1. 人 物流计划岗确认分仓销售计划与促销计划，设定本轮分货周期参数（促销放量、旬度进度）
  2. Agent 拉取全仓现货/在途/待检/合格库存与需求，按 DOS 分级识别全仓网缺口与积压
  3. Agent 汇总分货数据底表并校验字段口径完整性（可发量/待检/合格/在途/生产备货率/大日期）
  4. Agent 计算生产备货率/订单完成率与目标备货率、各仓补货优先级，多约束求解生成多版分配方案
  5. 人机协同 物流计划岗审核确认/微调分配量，Agent 重新校验库存/在途/效期/促销多约束
  6. Agent 生成标准化补货单并校验收发仓/SKU/数量/时效
  7. 人机协同 物流计划岗确认后下发（必停+10 秒撤销窗口），Agent 推送物流调度与财务核算
  8. Agent 抓取 TMS 在途定位、核对 WMS 入库差异，同步可发量/DOS 并预警
  9. 人机协同 物流计划岗审批复盘调参建议，参数下一周期生效
