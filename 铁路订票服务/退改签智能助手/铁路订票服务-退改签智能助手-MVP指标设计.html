退改签智能助手 · MVP 指标设计与上线门禁

为 退改签智能助手 建立从「原型通过」到「正式发布」的客观量化准则。

决策门禁 · Decision Gateway “当 退改签自助率 ≥95%、规则转译准确率 ≥98%、决策耗时 ≤ 秒级、退改交易失败率 ≤1%、关联服务遗漏率 ≤ 目标值 且 无依据推断率 ≤3% 时，允许灰度上线。” 通过门禁：允许发布 未通过：回归优化

核心成效指标（Success Metrics）

四维 · 13 项
指标 / 维度计算口径目标阈值
退改签自助率 业务
无需人工介入即完成退改签的订单数 / 退改签总订单数
来源：工作台流程日志 + 客服工单
≥ 95%
决策耗时 业务
从场景触发到方案选定的平均耗时
来源：流程埋点
秒级（基线 15–20 分钟）
高峰期改签成功率 业务
高峰期改签请求成功完成数 / 改签请求总数
来源：票务核心 + 推荐记录
提升（基线待回填）
关联服务遗漏率 业务
存在未处置关联服务的退改订单数 / 有延伸服务的退改订单数
来源：订单协同中心 + 一致性校验
≤ 目标值（待回填）
规则转译准确率 模型
转译说明金额/档位与规则引擎结果一致的样本占比
来源：离线测试集（AI 测试数据集）
≥ 98%
方案推荐采纳率 模型
旅客选定方案落在 Top 3 推荐中的比例
来源：推荐与选定记录
≥ 目标值（待回填）
无依据推断率（幻觉率） 模型
在规则/数据不足时仍给出确定性费率或方案的占比
来源：自研评估脚本 + 人工抽检
≤ 3%
接口成功率 系统
票务核心 / 运行监控 / 订单协同 / Push 成功调用占比
来源：接口网关监控
≥ 99%
P95 响应延迟 系统
95% 请求的端到端响应时间
来源：APM 监控
≤ 3s
退改交易失败率 系统
主票退改交易失败次数 / 交易总次数
来源：票务核心交易日志
≤ 1%
旅客操作步骤减少 体验
（改造前人工步骤 - 改造后人工步骤）/ 改造前人工步骤
来源：流程埋点对比
≥ 50%
方案卡片可理解度 体验
旅客对方案/费用说明的理解度评分（问卷/CSAT）
来源：体验问卷 + CSAT
≥ 目标值（待回填）
通知触达率 体验
成功送达的处置通知数 / 应通知总数
来源：Push 推送回执
≥ 95%
