关键旅程（订票→出行→后续服务）

  1. 意图形成 → 查询与筛选 → 方案决策
  2. 实名与规则校验 → 下单与支付 → 出票与凭证
  3. 出行前服务：改签退票 / 候补兑现 / 订餐 / 约车 / 重点旅客
  4. 站内/乘车：检票核验、运行变更处置
  5. 出行后服务：售后、遗失物品、投诉与客服

系统难点（含推断）

  • 峰值并发 + 公平性要求：高峰的关键指标不是日常吞吐，而是“可解释的排队与一致规则”
  • 规则复杂：票种/优惠/改签退票/候补/运行变更等造成高失败成本
  • 合规与隐私：最小必要、明示同意、第三方 SDK 信息披露
  • 反爬与异常流量：对高频刷票等异常行为的识别与限速/拒绝
