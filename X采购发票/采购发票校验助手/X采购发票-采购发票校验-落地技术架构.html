5 条链共享读写本体 / 按需调用 MCP
共享底座
🧱 本体（确定性底座）

读 R：发票 / 发票行（匹配主线）、PO / 入库单 / 送货单（三单匹配基准）、匹配关系表（不覆盖原始单据）、预制发票 / 会计凭证 / 台账（入账归档）。
写 W：结构化识别字段（识别回写）、匹配关系表（匹配回写）、预制发票 / 会计凭证（预制过账回写）、乐企入账状态 / 台账 / 归档索引（状态回写）。
对象 / 关系 / 状态迁移 + 业务事实；三单匹配、数量扣减与硬门禁走本体与规则引擎，不靠 LLM 猜事实。

🔌 MCP / 外部系统

调用点：乐企平台（IF001 发票拉取 / IF002 入账状态）、SAP ERP（IF003 PO / IF004 入库单 / IF005 预制 / IF006 过账 / IF007 凭证）、公共网盘（IF008 送货单）、文件服务（IF009）、OCR/AI 识别（IF010）、主数据（IF011/IF014）、权限 AD（IF015）、打印服务（IF016）、消息/IM（IF017）。
仅需要外部读写的步骤才走 MCP；送货单无 API，依赖公共网盘人工读取（⚠️系统孤岛）。

📚 知识库 / RAG

检索点：差异容忍与异常判定经验、异常沟通与升级路径、供应商/税号/科目映射字典、发票票面关键字段提取要点。
三单匹配/数量扣减/硬门禁走规则引擎而非向量检索；容忍经验、异常路径、字典、提取要点走 RAG。

🩷 异常池（人工终审）：重复/漏票 / 低置信识别 / 送货单缺失 / 差异超容忍 / 预制缺项 / 过账失败 / Loop 超限 → 升级人工，附上下文摘要。

失败 / 降级 / 兜底

触发处理类型
乐企 IF001 / ERP IF003–IF007 接口失败或超时重试 1 次 → 标记同步异常并通知 ITretry / escalate
票面识别置信度 <95% / 模糊票 / 新版式标红转人工复核补录，不阻塞其余字段fallback
送货单无 API、公共网盘读取失败标记系统孤岛缺口，转人工读取并留痕escalate
三单匹配差异超容忍（数量/金额尾差）必拉人确认，附四数量对照与判定依据escalate
预制硬门禁缺项（如成本中心缺失）入待补队列 + 降级建议（补项后重试 / 转人工）fallback
过账失败记录 ERP 返回 → 财务确认后手工重试，禁止无限制自动重试retry / escalate
跨 PO 权限操作不展示非权限数据，提示权限边界fallback

KPI 锚定（链路 → 指标）

发票票面识别准确率① 多源归集与票面识别　≥95%
采集归集覆盖率① 多源归集　全渠道 100%
三单匹配自动化覆盖率 / 匹配错误率② 三单匹配　自动匹配 + 超容忍必拉人
入账自动化覆盖率④ 预制过账 + ⑤ 台账归档回写　100%
单票校验耗时 / 异常处理周期② 匹配 + ③ 异常　逐票人工 → 秒级 + 异常分流

护栏落点

三单匹配与数量扣减为确定性规则以发票行为主线、三层匹配、发票数量扣减入库/送货数量；不校验入库单与送货单一致性，走规则引擎
金额比对由 ERP 模拟校验接口承载本平台仅感知通过/差异结果，不落地金额比对规则
过账为对外财务动作的强制人工闸门财务负责人确认后才过账，禁止静默通过
三类硬门禁前置预制/过账/乐企前置未满足一律阻断
差异容忍阈值为领域专家假设值数量无容忍区间、金额尾差 ≤1 元且 ≤0.5%（待访谈回填），不写成确定值
识别低置信不静默置信度 <95% 标红转人工复核
⚠️ 口径待确认：差异容忍阈值与异常类型清单为领域专家假设值；6 条匹配规则边界（行/总金额一致性、含税口径）、税额/单价/尾差规则清单待客户二轮访谈回填。
⚠️ 基线待回填：采购发票月度量级、单票校验耗时、三单匹配错误率（X/Y/Z）三项基线影响验收标定。
⚠️ MCP 边界：本方案把乐企/SAP/网盘/文件/OCR/主数据/打印/IM 画成 MCP 外部调用；若确认「MCP=0，数据全部来自绑定本体」，则归入本体/内部服务并标 N/A。
