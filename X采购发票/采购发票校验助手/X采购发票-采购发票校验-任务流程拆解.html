专家实际怎么做

证据 · 访谈走查

专家以发票行为主线（非整张发票粒度）把 PO 行、入库行、送货单行拉齐，支持一对一/一对多/多对多
数量以『发票数量扣减入库/送货数量』逐行核对，四数量对照（PO/送货/入库/发票）定位差异来源，不校验入库单与送货单一致性
金额以不含税金额为基准经 ERP 模拟校验接口比对，本平台仅感知通过/差异结果，不落规则
差异按容忍规则判定：数量无容忍区间、金额尾差 ≤1 元且 ≤0.5% 自动容忍、任一超容忍必拉人；差异记入匹配关系表不覆盖原始单据

行级核对数量并扣减
🤖 Agent 		三单行级匹配工作集（行数量） 行级数量核对结果、四数量对照报表（PO/送货/入库/发票） 决策模型类·三单匹配口径与数量扣减规则（发票数量扣减入库/送货） 数量超差（发票数量 > 入库/送货）→ 匹配差异确认点必拉人
行级核对金额与差异
🤖 Agent 		发票不含税金额、合同/PO 金额、ERP 模拟校验接口返回 行级金额核对结果（差异金额/差异率/接口判定） 决策模型类·金额比对规则（由 ERP 模拟校验接口承载，本平台仅感知结果） 金额超尾差/单价不符 → 匹配差异确认点必拉人
判定行级匹配结果并记录匹配关系
🤖 Agent 		行级数量/金额/物料/供应商核对结果 匹配结论（通过/差异）、匹配关系记录（差异类型/差异金额/差异数量） 决策模型类·差异容忍与异常判定经验（假设值，待访谈回填） 容忍内自动放行；任一超容忍 100% 拉人 → 异常确认点

发票行 + PO 行 + 入库行 + 送货单行 → 三单行级匹配工作集 → 行级数量扣减结果 + 四数量对照报表 → 行级金额核对结果（ERP 模拟校验接口） → 匹配结论（通过/差异）+ 匹配关系记录 → 下游：批量预制发票 / 异常凭证队列（补单换票后重跑）→ 会计凭证 / 台账归档
💡挖掘的关键

为什么这样拆？

每个 L5 各自只有一个核心动词（汇入 / 核对 / 判定），输入输出可列、结果可观察，并可独立挂接一类规则依据（三单匹配口径 / 数量扣减 / 金额比对 / 差异容忍）。

挖掘的关键不是改写名称

挖掘的关键不是改写任务名称，而是把专家真实执行的动作顺序（汇入→数量→金额→判定）、输入输出、判断依据（匹配口径/容忍阈值）和异常链路（超容忍必拉人、匹配关系表不覆盖原始单据）结构化。
