1. 对话式可执行订舱（问答升级为执行）
流程创新 根因：AI 问答对复杂多单、多单证处理有限，需频繁转人工，一次性解决率低 能力：Agent / 多轮任务执行 / 工具调用
1
① 机会点一句话描述
为 SME 货主与货代操作员构建「对话式可执行订舱」，把 AI 客服从「问答机器人」升级为「可执行订舱 Agent」，在对话中直接完成订舱、单证查询与异常处置。
2
② 业务角色及场景
角色：SME 货主直客（主）、货代 / NVOCC 操作员、人工客服 CSR。 场景：货主在聊天窗口 / 微信小程序用自然语言咨询或发起订舱，Agent 识别意图、融合上下文、检索知识并执行订舱动作，复杂问题附摘要转人工。
3
③ 问题痛点
AI 问答只能回答，无法执行；复杂问题转人工时需重复提供上下文，一次性解决率低，SME 全流程依赖人工。
4
④ 方案假设
用 Agent 编排：意图识别与路由 → 上下文融合 → 知识检索（RAG）→ 订舱执行（预填/校验/提交）→ 状态查询与异常处置 → 智能升级（附摘要）→ 闭环回写 CRM/OMS；对外放行动作保留人工闸门 → 把 AI 分流率推向 30%+。
5
⑤ 价值收益
AI 客服从问答走向可执行；AI 分流率 30%+；SME 全流程自助率提升。

发生频度⑤ 发生频度高频（每会话多次互动）

2. 报价逐项解读与舱位综合排序推荐
高认知辅助 根因：货主看不懂复合报价构成，舱位选择需权衡价格/交期/履约率，依赖人工解释 能力：确定性服务 / 排序模型 / LLM 解释
1
① 机会点一句话描述
为 SME 货主构建「报价逐项解读与舱位综合排序推荐」，把「人工解释复合报价、凭经验选舱」升级为「报价逐项解读 + 舱位综合排序 + 推荐理由可复核」。
2
② 业务角色及场景
角色：SME 货主直客（比价选舱）、货代操作员（批量比价）。 场景：货主输入询价需求，Agent 调报价引擎获取复合报价，逐项解读费用构成，并按价格/交期/履约率综合排序推荐 Top 舱位，展示打分依据。
3
③ 问题痛点
复合报价构成复杂、货主难以判断；舱位选择需在价格与交期间权衡，靠人工解释与经验，信息不对称。
4
④ 方案假设
报价与评分走确定性服务（LLM 不计算价格）→ 逐项解读费用构成 → 按加权因子综合排序 → 展示子分与推荐理由 → 货主确认（对外必停）→ 把询价到选舱的时长压缩。
5
⑤ 价值收益
报价解读与选舱从人工解释走向自动解读 + 综合排序；货主决策效率提升。

3. 订舱表单智能预填与规则校验
重复性替代 根因：3 步订舱表单字段多、校验规则 200+ 条，新客首单无历史数据预填不可用 能力：规则引擎 / 智能预填 / 确定性校验
1
① 机会点一句话描述
为 SME 货主与货代操作员构建「订舱表单智能预填与规则校验」，把「人工逐字段填写并核对校验规则」升级为「AI 智能预填 + 200+ 规则自动校验 + 缺项提示」。
2
② 业务角色及场景
角色：SME 货主直客（首单预填）、货代操作员（批量订舱）。 场景：Agent 依据会话上下文与主数据预填 3 步表单字段，运行订舱校验规则引擎（200+ 条）校验必填项与合规要求，缺项提示补录。
3
③ 问题痛点
订舱表单字段多、校验规则 200+ 条，新客首单无历史数据、Smart Push 预填不可用，人工填写慢且易错。
4
④ 方案假设
智能预填（主数据 + 会话上下文 + OCR 兜底）→ 订舱校验规则引擎（200+ 条）自动校验 → 缺项/冲突提示补正 → 表单确认后提交订舱请求 → 把订舱确认时效推向 ≤2h。
5
⑤ 价值收益
订舱表单从人工填写走向智能预填 + 规则校验；订舱确认时效 ≤2h；表单一次提交通过率提升。

4. 单证抽取预填与 SI 校验
重复性替代 根因：SI 等单证字段靠人工录入，单证规则库 300+ 条靠人工核对，缺件需往返补件 能力：OCR / 规则引擎 / 关联校验
1
① 机会点一句话描述
为货代操作员构建「单证抽取预填与 SI 校验」，把「人工录入 SI 字段、逐条核对单证规则」升级为「单证 OCR 抽取预填 + 300+ 规则校验 + 缺件检查」。
2
② 业务角色及场景
角色：货代 / NVOCC 操作员（SI 预填）、SME 货主（补件）。 场景：Agent 从贸易单据（PI/装箱单/发票）抽取字段预填 SI，运行单证规则库（300+ 条）校验，缺件禁止推送并提示补件。
3
③ 问题痛点
SI 字段人工录入慢，单证规则库 300+ 条靠人工核对，缺件导致往返补件（2~3 轮），单证一次提交通过率低。
4
④ 方案假设
单证 OCR 抽取 → 字段预填 SI → 单证规则库（300+ 条）自动校验 → 缺件检查（缺件禁止推送）→ 推送入库 → 把单证一次提交通过率提升、往返补件压缩。
5
⑤ 价值收益
单证预填从人工录入走向自动抽取 + 校验；单证一次提交通过率提升；往返补件 2~3 轮 → 1 轮。

5. 出运跟踪、延误预警与异常处置建议
高认知辅助 根因：出运状态多源分散，延误靠人工发现，异常处置依赖经验 能力：多源融合 / 预测模型 / LLM 建议
1
① 机会点一句话描述
为 SME 货主与 CSR 构建「出运跟踪、延误预警与异常处置建议」，把「人工多系统查轨迹、被动发现延误」升级为「多源轨迹融合 + 延误预测预警 + 改配/赔付建议」。
2
② 业务角色及场景
角色：SME 货主直客（跟踪）、CSR（异常处置）。 场景：Agent 融合控制塔 / Cargo Tracking+ 多源轨迹，预测 ETA 延误并预警，生成改配建议或赔付预判，对外动作转人工确认。
3
③ 问题痛点
出运状态分散在多个系统，延误靠人工发现，异常处置依赖经验，货主信息不对称。
4
④ 方案假设
多源轨迹融合 → ETA 延误预测（专用模型）→ 延误预警生成 → 风险高时生成改配/赔付预判（对外必停）→ 低风险降级为事后通知 → 把复杂问题一次性解决率与 CSAT 提升。
5
⑤ 价值收益
出运跟踪从人工查询走向多源融合 + 主动预警；异常处置有建议可循；CSAT 提升。

发生频度⑤ 发生频度事件驱动（状态变更 / 异常）
