🔹 流程说明

  • 主链路 P1→P2→P3→P4→P5→P6→P7，智能订舱 Agent 主驱动全程，人工仅在价值判断/风险兜底介入
  • 全场景核心确认点（PO/HITL 高）：P3 一键订舱确认（gate，对外必停）、P3 异常订舱人工终审、P6 延误处置、P7 复杂问题转人工
  • 新客首单：Smart Push 无历史数据，由会话上下文 + PI/装箱单 OCR 预填兜底，并标注置信度（承接 AI Canvas userPains）
