单证校验规则（VGM/毛重差异/HS） 使用点 · 单证校验（VGM/毛重差异/HS）
①决策因子
VGM 申报：核实的集装箱总重是否申报 (来源 智慧单证系统)
毛重差异：SI 毛重与装箱单/称重差异是否超限 (来源 智慧单证系统)
HS 编码：品名能否映射到合规 HS 编码 (来源 多语言品名/HS 字典)
→
②逻辑分支
VGM 缺失 → → 生成补全项 + 填写示例（如 12,900 KG）
毛重差异超限 → → 差异告警，提示一次补全
HS 编码无法映射 → → 提示人工复核，禁止猜测
→
③分支动作
运行 300+ 条单证规则，处理 VGM 缺件/毛重差异/HS 编码三类异常，禁止带缺件推送单证系统。
→
④冲突仲裁
VGM 缺失/毛重超限者阻止推送；HS 无法映射走人工复核，不阻塞主链路。
例外/HITL：VGM 缺失/毛重超限 → 生成补全项；HS 无法映射 → 人工复核
OCR 置信度与字段处理规则 使用点 · 抽取置信度标注使用点 · 确认并提交 SI
①决策因子
OCR 置信度：各字段抽取置信度分数 (来源 OCR 解析器)
字段类型：品名/唛头/件数/毛重/体积/HS (来源 抽取结果)
→
②逻辑分支
置信度高（≥阈值） → → 直接进入品名规范/HS 映射
置信度低（<阈值） → → 标黄待人工复核，不阻塞其余字段
关键字段异常未修正 → → 阻止 SI 提交
→
③分支动作
按 OCR 置信度决定字段处理路径，低置信度标黄复核，关键异常阻止提交。
→
④冲突仲裁
低置信度字段标黄复核而非静默按抽取值推送；关键字段（HS）异常未修正时阻止提交。
例外/HITL：OCR 置信度低 → 标黄待人工复核；异常未修正 → 阻止提交并给出示例

补件清单与示例模板
使用点 · 生成异常补全项与示例
固定骨架（章节 / 表头）
① 缺件项
固定：固定栏（字段名/缺失原因/示例值）
动态：随校验异常动态生成
② 填写示例
固定：固定栏（VGM 示例 / HS 映射示例）
动态：随字段类型生成
③ 复核提示
固定：固定栏（再校验路径/提交条件）
动态：随异常项生成
动态字段来源
缺件项.VGM ← 来自单证校验（VGM 缺失）
示例值 ← 来自历史补件样本 / 标准值模板
复核提示 ← 来自单证校验规则
生成规则：异常项必须给出填写示例；未展示原因与示例不得仅列缺件名。 合规：补件提示不得让操作员自行猜测口径；关键字段（VGM/HS）必须配套示例。
典型 · VGM 补件 · 展示缺失原因 + 12,900 KG 示例，操作员一次补全 反面 · 只标缺件无示例 · 禁止只列缺件名不给示例，否则操作员仍需二次询问
SI 提交模板
使用点 · 确认并提交 SI
固定骨架（章节 / 表头）
① 单证头
固定：固定栏（订舱号/船名航次/起运港/目的港）
动态：随订舱确认书填充
② 货载明细
固定：固定栏（品名/唛头/件数/毛重/体积/HS）
动态：随 SI 字段填充
③ 校验状态
固定：固定栏（VGM/毛重/HS 校验通过项）
动态：随校验结果填充
动态字段来源
订舱号 ← 来自订舱确认书 Booking 编号
货载明细 ← 来自 OCR 抽取 + 品名/HS 映射
校验状态 ← 来自单证校验结果
生成规则：校验全部通过才可提交；存在异常项必须带补件清单一起展示。 合规：不可带缺件推送；HS 无法映射时禁止提交猜测编码。
典型 · 校验通过 SI · 字段齐全、校验通过，一次提交成功 反面 · 带缺件提交 · 禁止 VGM 缺失仍提交，否则退单返工

单证预填业务口径词典 使用点 · OCR 抽取 SI 字段使用点 · 单证校验使用点 · 确认并提交 SI
SI
装运指示（Shipping Instruction），提单签发的依据
适用：OCR 抽取/提交
VGM
核实的集装箱总重（Verified Gross Mass）
适用：单证校验
HS 编码
海关商品编码，品名的合规申报用码
适用：品名/HS 映射
唛头
货物运输标志（Shipping Mark）
适用：OCR 抽取
毛重差异
SI 毛重与装箱单/称重的偏差
适用：单证校验
eBL
电子提单（Electronic Bill of Lading）
适用：单证进度
维护方：单证团队，随海关编码与口岸政策更新
引用范围：SI 字段抽取、品名规范、单证校验、补件
