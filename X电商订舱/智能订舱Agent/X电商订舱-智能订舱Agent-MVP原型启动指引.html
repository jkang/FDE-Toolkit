快速开始

在 X电商订舱/智能订舱Agent/mvp-prototype/ 目录下执行：

npm install        # 安装全部依赖（一次）
npm run dev        # 开发模式：API(:18081) + Vite 前端(:5173)

浏览器打开 http://localhost:5173

生产模式（单端口一体化）：npm run build && npm start → http://localhost:18081
