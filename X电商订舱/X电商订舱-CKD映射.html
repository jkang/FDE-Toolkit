核心资产与定义
意图分类 Prompt 模板

将货主咨询分类为询价/订舱/查询/投诉/单证等意图，含 Few-shot 示例与行业术语表，驱动 LLM 意图路由。

历史对话记录（脱敏）

货主近 N 轮对话与历史意图标签，用于多轮上下文继承与个性化。
产品 FAQ 与报价知识库

E-Spot/E-Quote/Secured E-Quote/舱位保证/增值服务说明，RAG 检索用于回答运价与产品咨询。

实时订单 / 船期 / 箱动态 API

OMS、船期系统与控制塔的实时状态数据，Agent 工具调用获取订单进度与跟踪里程碑。
订舱校验规则引擎

3 步表单必填项、费率/信用/航线校验规则，Agent 执行订舱前的自动校验逻辑。

货主信用与认证数据

企业认证状态、信用等级、会员等级，决定订舱放行与权益应用。
客服知识库与 SOP

疑难场景处理标准作业流程（改船/退款/投诉），用于生成转人工摘要与处理建议。

工单系统数据

货主咨询、工单状态与处理结果，Agent 自动建单与回写形成闭环。
历史成交价库

电商渠道历次 E-Spot/E-Quote 成交记录（含货量、航线、附加费），定价模型训练主数据。

市场运价指数（SCFI/CCFI）

外部市场行情指数与附加费规则（BAF/THC），外部信号用于运价走势预测。
锁价产品参数库

Secured E-Quote 期限、条款与履约记录，风险对冲模型的关键输入。

历史运价波动事件库

关税政策、红海绕航、运力过剩等事件对运价的影响样本，用于情景模拟与 VaR 测算。

货主价值与会员数据

货主价值分级与 PlumSmart 等级，支持差异化报价与舱位权益。
航线装载率与舱位余量

目标航次实时装载率与舱位余量，舱位分配预演与承诺兑现约束输入。

电商承诺兑现率指标（KPI 5）

Space Protection 产品历史兑现率，作为分配模型的硬约束与效果度量。
AIS 船舶动态

船舶位置、航速与历史航迹，ETA 预测与异常识别的核心信号源。

码头作业与拥堵数据

靠泊/装卸状态与港口拥堵指数，影响到港节点预测精度。

船期计划与联盟运力调整

海洋联盟 DAY9/DAY10 船期与运力变更，基线数据。
历史延误案例库

延误原因、时长分布与港口/航线特征，训练 ETA 延误概率模型。

港口拥堵特征库

码头作业效率、季节性拥堵模式，预测模型外部特征。
Delay in Transit 条款与赔付规则

2025.12 上线的迟延转运保障条款，自动生成赔付预判。

货主订阅偏好与通知渠道

货主对预警的订阅偏好与通知渠道（邮件/小程序/App），主动推送个性化。

改配与补偿 SOP

改船方案模板、免箱期政策与补偿标准，生成处置建议的知识基座。
贸易单据扫描件（PI/装箱单/发票）

OCR 与文档智能解析的原始输入，抽取品名、唛头、数量、重量字段。

多语言品名词典与 HS 编码库

中英西日等多语言品名规范化对照与海关 HS 编码映射，合规校验知识基座。
历史 SI 样本库（校验通过）

35 万份/年自动处理沉淀的历史样本，训练校验与纠错模型。

单证校验规则库

必填项、格式、VGM、舱单与监管申报规则，自动校验逻辑来源。
IQAX eBL / GSBN 互操作规则

IG P&I 互操作批准标准与跨平台规则，判断 eBL 可签发与流通范围。

收货人 / 银行 eBL 接入状态

贸易链各节点的 eBL 接入度与活跃度，用于渗透引导与互操作预判。
订舱交易序列

订单时间、航线、货量、箱型与金额的时序序列，复购与流失预测主数据。

货主行为事件流

浏览报价、询价、客服互动、App 使用等行为事件，行为特征补充。
历史流失货主样本

流失货主流失前的行为模式，训练流失预警与复购概率模型。

会员等级与权益规则库

PlumSmart 等级规则与权益定义，生成升级路径建议与权益组合。
权益 / 促销效果数据

E-Spot Flash Sale、Promo Code、Smart Combo 历史转化与复购拉动效果，推荐模型训练数据。

舱位余量与闪购放量计划

促销与舱位保证强耦合的放量计划，避免权益承诺落空。

CRM 货主标签体系

货主画像标签与分层，个性化触达与挽留动作的目标圈选。
