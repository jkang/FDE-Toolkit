快速开始

在 X销售收入确认/POD收入确认/mvp-prototype/ 目录下执行：

npm install        # 安装全部依赖（一次）
npm run dev        # 开发模式：API(:8080) + Vite 前端(:5173)

浏览器打开 http://localhost:5173

生产模式（单端口一体化）：npm run build && npm start → http://localhost:8080
