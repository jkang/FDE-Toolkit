为 销售POD收入确认工作台 建立从"原型通过"到"正式发布"的客观量化准则。

Decision Gateway Criteria

“当 采集自动化率 ≥85%、字段识别准确率 ≥95%、差异归因准确率 ≥90%、POD 确认合规率 100%、SAP 接口成功率 ≥99% 且 过账失败率 ≤1% 时，允许灰度上线。”

通过门禁：允许发布
未通过：执行回归优化

测试数据集策略

Golden Path 50%
验证核心功能链路与基准准确率。

Hard Cases 29%
检验模型处理复杂边界逻辑的鲁棒性。

Edge Cases 21%
测试系统异常处理与内容安全边界。

Evidence Tags

测试集必须包含中间产物标签（如检索 ID、提取字段），以便在指标未达标时进行归因分析。

四维一线法

MVP 验证不应仅看准确率，必须同步评估业务采纳、系统延迟与成本。只有四维达标，才具备发布资格。
