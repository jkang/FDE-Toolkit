AI 人机流程
改造后的完整人机协同流程（人 / Agent / 人机协同）
  1. 人 物流 / CS 发起或系统定时拉取，进入销售POD收入确认工作台
  2. Agent 定时读取公共邮箱与公共文件夹，识别交货单-发运单关联与签收 / POD 资料并结构化落库
  3. 人机协同 低置信度识别进入人工复核，物流补充资料或补邮件留痕
  4. Agent 按客户 / 周期同步 SAP 交货单，生成对账单供 CS 下载
  5. 人 CS 下载对账单给客户确认，上传客户反馈
  6. Agent 自动比对客户反馈与 SAP，输出差异归因与借贷项建议
  7. 人 CS 确认差异并处理借贷项（未完成不开放 POD 确认）
  8. Agent 校验 POD 确认条件，汇总横向匹配表与缺口提示
  9. 人 CS 一键 POD 确认（对外确认收入的闸门）
  10. Agent 自动生成预制发票；财务过账、打印、归档；驾驶舱与综合查询更新
