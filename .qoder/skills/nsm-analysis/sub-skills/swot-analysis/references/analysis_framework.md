# SWOT 分析框架

## 分析维度详表

### 内部因素评估

**优势（S）评估清单**：
1. 该业务的核心竞争壁垒是什么？（技术、数据、品牌、规模）
2. 与主要竞品相比，有哪些不可复制的差异化能力？
3. 现有资源（用户、数据、资金）如何支撑该业务？
4. 组织能力或人才优势体现在哪里？

**劣势（W）评估清单**：
1. 该业务发展的最大内部瓶颈是什么？
2. 与竞品相比，在哪些维度明显落后？
3. 资源投入是否充足？有哪些资源约束？
4. 组织架构或文化上有哪些制约？

### 外部因素评估

**机会（O）评估清单**：
1. 行业未来 1-2 年的增长动力在哪里？
2. 有哪些技术变革（如 AI）可以利用？
3. 政策或监管变化是否带来新空间？
4. 竞争对手有哪些没覆盖的需求缺口？

**威胁（T）评估清单**：
1. 最强竞争对手的下一步可能是什么？
2. 有哪些新进入者或替代品正在崛起？
3. 监管趋势是否对该业务不利？
4. 宏观经济或行业周期性风险有多大？
