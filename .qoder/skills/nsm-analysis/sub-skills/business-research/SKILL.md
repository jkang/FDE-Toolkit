# Business Research Skill

收集目标企业近 2 年的关键业务信息，输出结构化的业务现状报告。**注意：请务必根据当前系统时间推算“近 2 年”的具体年份（例如当前为 2026 年，则重点收集 2024 和 2025 年的数据），切勿使用过期的历史年份。**

## 执行预检与降级方案

在开始搜索前，**必须先进行环境预检**：

1. **评估工具可用性**：判断你当前的运行环境是否能够正常调用互联网搜索（如 `search_web`）和网页抓取能力（如 `read_url_content` 或 `read_browser_page`）。
2. **正常执行分支**：如果你具备这些工具，请默默开启搜索流程。**极度重要：严禁仅依靠搜索引擎的 Snippet 摘要生成报告！必须结合抓取工具点开目标链接，读取全文正文数据！** 不要询问用户，直接向下执行。
3. **降级执行分支（无工具时）**：如果你明确知道自己**无法连接网络或搜索工具不可用**，请停止执行，并向用户发送以下话术：
   > "我当前的环境无法直接搜索互联网。请您提供以下材料（或其链接/文件），我将基于您提供的材料进行分析：
   > 1. 该企业近 1-2 年的年报/财报 PDF
   > 2. 官网相关介绍页面或截图
   > 3. 行业分析报告"

   收到用户提供的材料后，继续基于材料完成后续分析，并在报告开头显著位置标注：*"（注：本报告基于用户提供的静态材料生成，未进行全网实时搜索）"*。

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 企业名称 | 是 | 调研目标公司 |
| 业务类型/模式 | 是 | 要重点关注的业务方向 |
| 行业关键词 | 否 | 缩小搜索范围 |
| 竞品列表 | 否 | 竞争格局对标 |

## 执行步骤

1. **工具预检** — 按上述要求检查网络搜索能力
2. **执行搜索/读取** — 按照下方的"搜索策略"先搜索，再强制使用 `read_url_content` 读取高价值网页全文。
3. **多维提取** — 按照下方的"收集维度"提取关键数据
4. **生成报告** — 按模板输出内容
5. **出口自检** — 检查质量清单，修正后输出最终结果

## 搜索策略

按以下优先级搜索信息：

1. **财报/年报** — `"{企业名称} 年报 {年份}"` `"{企业名称} annual report {年份}"`（自动替换为推算出的最近两年）
2. **官网** — 访问官方网站的产品介绍、新闻、投资者关系页
3. **行业报告** — `"{行业} 行业报告"` `"{企业名称} 市场份额"`
4. **新闻动态** — `"{企业名称} {业务类型} 最新动态"` 限近 12-24 个月

每条搜索结果记录来源 URL，确保可追溯。

## 收集维度

按 6 个维度整理信息，详细框架见 [collection_framework.md](references/collection_framework.md)：

1. **财务概况** — 营收、利润、增长率
2. **核心业务** — 产品/服务、市场份额、用户规模
3. **组织与人才** — 架构、关键人才、规模变化
4. **技术能力** — 技术栈、AI/数据能力、研发投入
5. **市场与客户** — 目标市场、客户画像、获客渠道
6. **战略动态** — 近期举措、收并购、新业务

## 输出格式

输出 Markdown 格式的业务现状报告，模板见 [collection_framework.md](references/collection_framework.md) "报告模板"部分。

## 出口质量自检

完成报告后，逐项核对以下清单。不通过的项需补充或修正后再输出：

- [ ] **来源标注**：每个关键数据点都标注了信息来源（URL 或文档名）
- [ ] **时效性**：数据在近 2 年时间窗口内（必须匹配推算出的最新年份，如 2024-2025）
- [ ] **六维覆盖**：6 个收集维度均有内容，找不到的明确标注"未找到公开数据"
- [ ] **业务聚焦**：内容围绕用户指定的业务类型/模式展开，非泛泛公司介绍
- [ ] **事实与推断分离**：推断处标注"[推断]"
- [ ] **无编造**：未出现无来源的具体数字或排名
