# 品牌 × 业务主题 → 定制产品设计语言矩阵（UX-Optimizer 核心参考）

本文件是 `ux-optimizer` 的**原创核心**。它回答了 UX-Optimizer 最重要的命题：

> 一款企业级产品 UI 的专业度，取决于 **「企业品牌基因」与「业务主题气质」** 的精准融合。
> MVP-prototype 不是咨询报告，它是**产品**——必须拥有自己专属、独立于 `design.md` 的设计语言。

---

## 一、推导框架

```
① 企业品牌画像 (Brand Persona)  ←  4 问，定"人格"
        ×
② 业务主题气质 (Domain Tone)    ←  业务域 × 具体场景，定"功能气质"
        ↓
③ 融合输出：定制设计语言 8 维 (Design Language)
```

与 `design.md` 的**关系**：完全解耦。`design.md` 只在 discovery 报告类产物上生效；本矩阵只服务于 MVP-prototype 产品类产物。

---

## 二、① 企业品牌画像 4 问（定"人格"）

| # | 维度 | 取值为 | 影响的设计维度 |
|---|------|--------|----------------|
| 1 | **品牌主色 / 调性** | 信任蓝 / 科技感深蓝 / 奢华金 / 沉稳灰 / 活力橙 / 医疗青绿 | 主色、色彩语义、渐变、氛围 |
| 2 | **用户群体** | 内部员工 / 客户 / 经销商 / 终端消费者 | 信息密度、措辞、复杂度、字体大小 |
| 3 | **场景严肃度** | 合规严苛 / 严谨流程 / 开放协同 | 圆角、间距、色彩克制度、动效 |
| 4 | **品牌成熟度** | 传统巨头 / 专业细分 / 新锐 | 布局模式、动效大胆度、渐变使用 |

### 2.1 四问的启发式取值示例

**品牌主色→语义基调**
| 品牌色 | 基调词 | 产品氛围 |
|--------|--------|---------|
| 信任蓝 (#2563eb) | 可靠、专业 | 标准企业级，稳重克制 |
| 科技深蓝 (#1e3a5f→#4A9FD8) | 深度、未来 | 金融/大屏，有科技纵深感 |
| 奢华金 (#c9a227) | 权威、高端 | 高端制造/金融，质感厚重 |
| 沉稳灰 (#64748b) | 现代、中性 | 企服/外企，克制高级 |
| 活力橙 (#f97316) | 效率、行动 | 供应链/物流，强调行动力 |
| 医疗青绿 (#0d9488) | 治愈、可信 | 医疗/健康，放松可信 |

**用户群体→信息密度**
| 群体 | 密度 | 说明 |
|------|------|------|
| 内部员工 | 高密度 | 表格、字段多，效率优先 |
| 客户 | 中密度 | 平衡信息量与引导 |
| 经销商 | 中高密度 | 订单/库存/政策，重数据 |
| 终端消费者 | 低密度 | 大图大字，情感与信任 |

**场景严肃度→克制度**
| 严肃度 | 圆角 | 间距 | 动效 |
|--------|------|------|------|
| 合规严苛 | 小 (4-6px) | 紧 | 无/极简 |
| 严谨流程 | 中 (8px) | 中 | 克制 (0.15s) |
| 开放协同 | 大 (10-12px) | 疏 | 微生动 |

**品牌成熟度→大胆度**
| 成熟度 | 渐变/修饰 | 大胆度 |
|--------|----------|--------|
| 传统巨头 | 少，稳 | 低 |
| 专业细分 | 适度 | 中 |
| 新锐 | 大胆，可渐变 | 高 |

## 三、② 业务主题气质（定"功能气质"）

### 3.1 业务域气质
| 业务域 | 气质 | 关键词 |
|--------|------|--------|
| 供应链 / 采购 / 制造 | 行动、精准、协同 | 结构、表格、状态流 |
| 金融 / 银行 / 保险 | 权威、稳健、可信 | 数据看板、严谨、留白 |
| 医疗 / 健康 | 治愈、专业、安抚 | 引导、呼吸感、信任 |
| 零售 / 电商 | 活力、转化、消费 | 高屏效、图片、情感 |
| 企业服务 / 办公 | 效率、现代、协作 | 清单、列表、协作 |
| 教育 / 培训 | 启发、成长、陪伴 | 进度、路径、鼓励 |

### 3.2 具体场景气质（一阶修正）
同业务域下不同场景会有细分气质，例如：
- **售后理赔**：引导式分步 + 状态流转 + 信任背书（进度条、时间线、材料清单）
- **海外销售**：客户画像 + 大图展示 + 高转化 CTA（视觉冲击 + 明确行动）
- **订舱 / 物流**：实时状态 + 密集数据 + 突发事件预警（状态时间轴、告警、数据看板）
- **采购下单**：高效表单 + 库存可视 + 审批流（表单大屏 + 审批状态）

## 四、③ 融合输出：定制设计语言 8 维 (Design Language)

融合 `①人格 × ②功能气质`，产出 8 个维度的具体值。每个维度都量化到可直接落地。

| # | 维度 | 内容 | 落地载体 |
|---|------|------|---------|
| 1 | **色彩系统** | 主色(由品牌推导)+完整色阶 + 语义色(success/warning/danger/info) + 中性色板 | `tokens.js` |
| 2 | **字体系统** | 品牌/业务字体，全层级(标题/正文/标签/注释)有明确字号/字重/行高/字距 | `tokens.js` + `override.css` |
| 3 | **间距 & 栅格** | 8pt 节奏 scale `4/8/12/16/24/32/48`，内容宽度，卡片内距 | `tokens.js` |
| 4 | **圆角 / 阴影 / 边框** | 按气质定圆角；蓝色相阴影；边框强度 | `override.css` |
| 5 | **组件设计语言** | 11 类元素视觉/交互升级（见 `component_specs.md`） | `override.css` + `component_specs` |
| 6 | **状态体系** | hover / focus / empty / loading / error / disabled 六态完备 | `component_specs` + `override.css` |
| 7 | **布局模式** | 工作台 / Hero+看板 / 引导式分步 / 表单大屏（按场景选型） | `layout` 决策 |
| 8 | **微交互 & 响应式** | 0.15s ease-out 克制动效 + 375/768/1024/1440 断点 | `override.css` |

## 五、预置产品 UI 模式（起点模板，再按品牌增量定制）

为保证"精心设计"而非每次从零，预置 4 套产品 UI 模式作为推导起点：

| 模式 | 适用 | 布局特征 | 视觉气质 |
|------|------|---------|---------|
| **Modern SaaS 工作台** (默认) | 企服/供应链/内部系统 | 侧边栏+顶栏+卡片/表格 | 现代、结构、效率 |
| **金融数据看板** | 金融/银行/保险 | Hero 指标区 + 图表 + 深色局部 | 权威、纵深、稳 |
| **医疗引导式** | 医疗/健康/教育 | 分步引导 + 进度 + 大卡片 | 治愈、呼吸、可信 |
| **消费感大屏** | 零售/电商 | 搜索 + 竖卡 + 大图 + 转化 CTA | 活力、高屏效、情感 |

> 选定起点后，**必须叠加 `①企业品牌画像` 的差异化增量**（换主色、调圆角、动效、密度、布局微调），确保"这个企业的产品"，而非通用模板。
