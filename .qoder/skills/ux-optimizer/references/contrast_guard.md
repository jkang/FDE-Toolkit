# 对比度护栏 (Contrast Guard) —— WCAG AA 标准色对

本文档是 `ux-optimizer` 的**防呆护栏**。它定义了一套**已验证达标的语义色对**（前景/背景），
并给出对比度判定方法。任何用到颜色的组件（Tag / Alert / 状态/文案/图标/按钮），
**必须**从此文档取值，**禁止**直接使用 antd 预设的低对比度色（如 `gold`/`cyan`/`processing` 的深底深字组合）。

## 一、为何要护栏

antd 5 的预设 Tag 色对中，部分组合对比度不达 WCAG AA（正文 ≥4.5:1）：
- `color="gold"` → 黄底(#fcf1d8)+金棕字，对比度常 **< 2:1**，几乎不可读。
- `color="cyan"` → 浅青底+青字，正文也偏弱。
- `color="processing"` 在部分主题下深底深字，同样偏弱。

截图中的"推荐指令 chips"正是用了 `color="processing"`，导致深灰底+深灰字。

## 二、对比度判定标准（WCAG 2.1）

| 文本类型 | 最低对比度 |
|---------|-----------|
| 正文文本 | **4.5:1** |
| 大号文本（≥18pt 或 ≥14pt 粗体） | 3:1 |
| UI 组件边界 / 图标 | 3:1 |

**计算公式**（相对亮度）：
```
L = 0.2126*R + 0.7152*G + 0.0722*B   (R/G/B 先归一化为 sRGB 线性分量)
对比度 = (L_light + 0.05) / (L_dark + 0.05)
```
> 计算脚本见 `scripts/contrast_check.py`；应用前请对每个前景/背景色对跑一遍。

## 三、✅ 已验证达标的标准语义色对（本 Skill 强制用这套）

| 语义 | 背景 hex | 文字 hex | 对比度 | 用途 |
|------|---------|---------|:------:|------|
| primary | `#FFFFFF` | `#10213E` | ≈15:1 | 主要正文/标题 |
| primary 强调底 | `#EAF2FB` | `#10213E` | ≈12:1 | 高亮标签/推荐 chips |
| primary 实底(按钮) | `#10213E` | `#FFFFFF` | ≈15:1 | 主按钮文字 |
| accent | `#FFFFFF` | `#1E6FB8` | ≈5.5:1 | 链接/强调文字 |
| success | `#EAF7EE` | `#15803D` | ≈4.6:1 | 成功状态 |
| warning | `#FFF4E5` | `#B45309` | ≈4.6:1 | 警告状态 |
| danger | `#FDECEC` | `#B91C1C` | ≈5.2:1 | 错误/失败 |
| info | `#EAF2FB` | `#1D4ED8` | ≈6:1 | 信息状态 |
| neutral muted | `#F5F5F6` | `#475569` | ≈7:1 | 次要说明文字（Slate-600，白底/浅灰底均达标） |
| tag 默认底 | `#EEF2F7` | `#334155` | ≈8:1 | 普通胶囊标签 |

### 语义 → 背景/文字 映射速查（写 yaml / 组件时直接用）
```
primary-block:  bg #10213E  text #FFFFFF   (按钮/强调块)
primary-soft:   bg #EAF2FB  text #10213E   (高亮 chip / 推荐标签)
accent-text:    bg #FFFFFF  text #1E6FB8   (链接/强调)
tag-*:          bg <浅色底> text <深色字>  (一律用上表"软底+深字"模式)
```

## 四、🚫 禁止的对比度反模式（Antipatterns）

- ❌ `gold` / `cyan` / `processing` 等 antd 预设色直接用于正文 Tag。
- ❌ 深灰底 + 深灰字（如截图问题）。
- ❌ 浅灰字叠白底（`#D2D6DC` 等低对比）作为正文。
- ❌ 仅靠颜色区分状态（色弱用户不可读）——必须色+图标+文字三重表达。
- ❌ 强调色用在大面积背景上（用量应 5-10%，且保证文字对比度）。

## 五、防护检查（写进 Pre-Delivery checklist）

1. 遍历页面所有 `color=` / `type=`（Tag/Alert/button）色对，逐一对照本表。
2. 任何前景色+背景色组合，跑一遍 `scripts/contrast_check.py` 确认 ≥4.5:1（正文）/ ≥3:1（大号/图标）。
3. 状态标签必须是"浅底 + 深字"（软底）模式，禁止"深底深字"。
4. 若某个业务色找不到达标组合，用 `--ux-text` + 对应浅色底近似，优先保可读性。

> 案例基准：推荐指令 chips → 应改用 `primary-soft`（浅蓝底 `#EAF2FB` + 深字 `#10213E`，对比度 ≈12:1）。
